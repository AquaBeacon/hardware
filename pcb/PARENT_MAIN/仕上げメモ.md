## 2026-07-24 更新

- **I2Cプルアップ 4.7k×2 (R_SDA/R_SCL, V3D) を基板搭載**。DS3231モジュール(ZS-042)の
  搭載プルアップ依存を解消し、モジュール無しでもI2Cバスが成立。JLC Basic C23162。
  配置はJ_PWR1(I2C入口)脇 (32,10)/(36,10)。
- 旧「整容のみ」だった **F.Cu GNDベタ孤立島4件を根治**: `pcb/probe_islands.py` で
  島位置と安全打点を実測し、GNDスティッチビア4個を `seed_vias` に追加
  ((122.9,97.1)/(17,39.3)/(110.8,24.2)/(122.64,23.3))。孤立化した旧ビア(60,30)は除去。

## v4.0の主な変更（v3.3から）
- 受動部品を全SMD化（抵抗0603 / 100n=0603 / 10u=0805 / LED=0805 / 2N7002=SOT-23）。JLCPCB Basic志向。
- **UI基板を廃止**しスイッチを本基板へ統合:
  - 3ボタン（UP/ENT/DN、THT 6mmタクト）＋ADC抵抗ラダー1本化（BTN_ADC: UP=0V/ENT=0.82V/DN=1.65V/無=3.3V）
  - LCDバックライト（BL_PWM→R_G→2N7002→LEDBL_K, V3D→R_BL→LEDBL_A）
  - LCDリセットRC（R_RST/C_RST、GPIO非消費）
- コネクタは **LCD専用 J_LCD1（9ピンXH）** に変更（旧J_UI1=8ピンTO_UI廃止）。
- 外形 160×108 → **182×116mm**（UI部品収容のため拡大）。
