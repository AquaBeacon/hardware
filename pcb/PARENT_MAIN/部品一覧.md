# PARENT_MAIN (P-MAIN) 部品一覧

親機メイン基板で**実際に使う部品**と、その仕様（データシート・CAD図・寸法図・ピン配置）への
リンク集。回路設計・部品配置・定数決めの前に、必ずここのリンク先で
**ピン配置 / 外形寸法 / 電気特性**を確認すること。

- 対応生成スクリプト: `pcb/build_parent_main.py`
- 基板バージョン: **P-MAIN v5.5**（2026-08-02）。SPRESENSE拡張ボード使用・JP1=3.3Vを反映し、
  同期信号は各100Ω直列で接続。`J_SPR1` pin4はNC。I²Cプルアップは4.7k DNP選択。
  ERC合格・netlist一致(36ネット)・DRC違反0・未接続0。
- 旧: v5.1（2026-07-31 基板間コネクタ整合 / Pico 2 W(rot180)。**P-PWR とのコネクタ不整合を解消**: `J_PWR1` を P-PWR `J_MAIN` と同順へ、`J_I2CP`(XH5) 新設で GP3=`INA_AL`。**親機TXを `TX_improved`(1石)に確定**し `J_TX1`(XH2)/`J_TXT1`(XH3) に分割、`PWM_B`/`TX_EN` 廃止。外形112×88mm・取付穴M3×4はC-MAINと同一＝筐体共用可。下辺=Pico USB と microSD の挿入辺。全36ネット自動配線完了/DRC違反0）
- 旧: v5.0（2026-07-25 小型化 182×116→112×88）/ v4.0（SMD化+UI基板統合）
- ネット定義の正: `../docs/AquaBeacon_MAIN_UI_GPIO_コネクタ表.md`

> **記入ルール**：1部品につき**リンクを最低1つ**（できれば ①データシート/寸法図 ②CAD/3Dモデル
> ③購入ページ の3種）を必ず貼る。CAD図・機械寸法のある一次資料（メーカー公式）を優先する。

#### 基板への反映（**P-MAIN v5.3で反映、現行v5.5**）

`build_parent_main.py` を修正して再生成済み。現行v5.5の結果: **ERC合格 / netlist一致(36ネット) / DRC違反0 / 未接続0**。

1. ✅ **`J_LCD1` を XH9 → XH7 に縮小**。ピン順: `GND / V3D / I2C_SDA / I2C_SCL / LCD_RST / LEDBL_A / LEDBL_K`
2. ✅ **`LCD_CS`(GP14) と `LCD_DC`(GP19) を解放（NC）**。SPI1 は microSD 専用になり、
   「microSD と LCD で SPI1 共有」の制約も解消
3. ✅ **`R_BL` を 33Ω → 100Ω、上流を `V3D` → `V5D` へ**。
   3.3Vレールでは VLED typ 2.96V に対し余裕が 0.34V しかなく、VLED公差 2.88–3.12V で電流が 2.3倍ばらつく。
   5Vなら (5−2.96)/(100+RDS(on)≈7) ≈ **19.1mA**（VLED公差込みで 18.4–20.8mA）と安定。`V5D` は `J_PWR1` で本基板に来ている
4. ✅ **I²Cアドレス 0x3E(7bit) は既存デバイスと衝突しない**（DS3231=0x68 / AT24C32=0x57 / LIS3MDL=0x1C or 0x1E / MS5837=0x76 / TSYS01=0x77 / INA226=0x40台）
5. ✅ **Pico 2 W のピン配置を公式資料で照合済み**。物理19=GP14 / 物理25=GP19 / 物理6=GP4(**I2C0 SDA**) / 物理7=GP5(**I2C0 SCL**)。
   KiCad シンボル `MCU_Module:RaspberryPi_Pico` のピン番号は実機の物理ピン番号と一致（`probe_pins.py` 実測）。
   ローカル: `pcb/datasheets/RaspberryPi_Pico2W_datasheet.pdf` / `RaspberryPi_Pico2W_pinout.pdf`
6. ⚠ **未着手: LCD直近に昇圧C×2を載せる小型キャリア基板**（LCDは1.5mmピッチTHT直付け前提でコネクタが無いため）。
   Newhaven純正の `NHD-PCB0216CZ`(¥2,259) は **CZシリーズ用でCiZ非対応**、`NHD-PCB40` は汎用ブレークアウト。
   自前で 57×20mm程度の基板を起こすのが安価かつ確実（既存 `pcb/build_*.py` パイプラインで生成可）。**親子共通にできる**
7. ✅ **C-MAINもv4.1（2026-08-02）で反映済み**。親子で同一LCD・XH7ピン順。

> 補足（再生成時のハマり）: `R_BL` の V3D→V5D 変更で全体が再配線され、**`C_SD2`(0805 SMD)の GNDパッドが
> I2C_SCL/I2C_SDA/V3D に囲まれて F.Cu 上で孤立**した（`C_SD1` は THT なので B.Cu 主ベタへ素通しで無事）。
> B.Cu の島直下は `SD_CS`(x≈45.95) と `SD_CD`(x=47.10) の縦線に挟まれ 0.85mm しか無くビアが入らないため、
> 島ポリゴンの内包判定と両層クリアランス実測で唯一の実用解 **(46.70, 69.30)** を求めて `seed_vias` に追加した。
