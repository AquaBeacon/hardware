# TX_improved 基板仕様書

200kHz 水中音響ビーコン (TD04A) の**送信基板・標準版**。マイコンの 3.3V PWM を 12V の
ゲート駆動に変換し、1石の N-ch MOSFET で L1 と振動子容量 C0 の共振タンクを叩いて、
12V 電源から **45Vpp** の駆動振幅を作る。

- 生成スクリプト: **`pcb/build_tx_improved.py`**（このファイルが唯一の真実。`.kicad_sch` / `.kicad_pcb` は直接編集しない）
- LTspice: `LTspice/TX_improved.asc`、検証 `sim/tx_improved_verify.py`、記録 `sim/notes.md` §1 / 2026-07-19節
- 上流: 親機 **P-MAIN**（`J_TX1` / `J_TXT1`）と **P-PWR**（`J_TX` = 12V）
- 部品と一次資料リンク: **`部品一覧.md` は未作成（要作成）**。データシートは `pcb/datasheets/` に
  `2SK4017_toshiba.pdf` / `Toroidal_L_TCV-471M-2.5A-5026_akizuki.pdf` / `XT30PW-M_akizuki_117949.pdf` がある
- 版数: **v1.1**（2026-07-19 TC4427化 / 2026-07-20 温度監視追加 / 2026-08-11 本書作成）

## 1. これは何回路か（呼び名）

**「1石（シングルエンド）LC 共振駆動回路」** と呼ぶのが一番正確で通りが良い。
基板単位で言うなら **「200kHz 超音波送信ドライバ（1石共振型）」**。

段で分けるとこう名乗れる:

| 段 | 呼び名 | 部品 |
|---|---|---|
| ① | **ゲートドライバ段** | U1 TC4427（3.3V ロジック入力 → 12V 出力） |
| ② | **ローサイド Nch スイッチ段（インダクタ負荷）** | Q1 2SK4017 |
| ③ | **LC 共振タンク** | L1 470µH + 振動子の制動容量 C0（1260pF 想定） |
| ④ | **保護** | D1/D3 TVS、D2 ゲートツェナー、R2 プルダウン、R3/R4 |

### これ**ではない**もの（名前が怪しく感じる原因はここ）

| 呼んではいけない名前 | 理由 |
|---|---|
| クラスD アンプ | クラスD は相補スイッチ（ハイサイド+ローサイド）+ 出力 LC フィルタ。本回路はスイッチ1個 |
| ハーフブリッジ / フルブリッジ | 同上。スイッチが1個しかないので「ブリッジ」ではない |
| トランス昇圧型 | それは **TX_advanced**（2SK4017×2 プッシュプル + 1:5 CT トランス）。本基板にトランスは無い |
| リニアアンプ / B級・AB級 | Q1 は完全にスイッチとして使う（オンかオフのみ）。線形領域を使わない |
| 「直列同調」 | ドレインノードから見ると L1 と C0 は**並列共振タンク**。V12 は C1 470µF / C2 100n で AC 的に接地されているため、L1 の上端は AC グラウンド。`README.md` の「直列同調L1」は緩い表現（§9-6） |

### 動作クラスとして厳密に分類するなら

**「有限給電インダクタ型クラスE に近い（quasi-Class-E）」**。
クラスE そのものと言い切らない理由は 2 つ:

1. L1 は RF チョークではなく**共振素子そのもの**（470µH は C0 1260pF と 206.8kHz で同調する値）
2. 出力側に直列共振フィルタが無く、負荷（振動子）＝ドレインのシャント容量そのもの

ただし LTspice では **Vds 最小値 = −0.69V**（＝ボディダイオードが導通するところまで振り切れている）
なので、実質 ZVS に近い動作になっている可能性は高い。**スイッチング時刻との位相関係は未確認**なので、
「ZVS 設計である」とは書かないこと。

### 昇圧の直感的な説明

Q1 が ON の間に L1 に電流を溜め、OFF にした瞬間その電流が行き場を失って C0 に流れ込み、
ドレイン電圧が跳ね上がる（誘導性キック＝フライバックと同じ現象）。これを共振周波数で
繰り返すので、タンクの Q 倍まで振幅が育つ。結果 **12V → Vds ピーク 45.1V（3.76倍）**。

## 2. 信号チェーン

```
[電源系]
J1 (XT30, 12V from P-PWR)
 └ V12 ─┬─ D3 SMBJ15A → GND     (電源側 TVS)
        ├─ C1 470µF/25V          (バーストのエネルギー源。P-PWR 側検証では "Ctx")
        ├─ C2 100n
        ├─ C4 10µ + C3 100n      (U1 ローカルバルク + パスコン)
        ├─ U1 pin6 (VDD)
        └─ L1 470µH ─→ DRAIN     ★共振インダクタ（チョークではない）

[駆動系]
J2 (PWM_IN, from P-MAIN J_TX1)
 └─ R1 100Ω ─→ INA ─ U1A TC4427 ─→ OUTA ─ R5 10Ω ─┬─ GATE ─ Q1.G
                                                    ├─ R2 10k → GND   (電源投入時/ケーブル外れ時に OFF を保証)
                                                    └─ D2 GDZJ15C 15V → GND (VGSS ±20V 保護)

[出力系]
DRAIN ─┬─ Q1.D (2SK4017 ローサイドスイッチ、S = GND)
       ├─ D1 SMBJ48A → GND      (振動子外れ時のドレイン過電圧クランプ)
       └─ R3 10Ω ─→ XD ─┬─ R4 100k → GND   (ブリード / DC 経路)
                          └─ J3 (端子台) → TD04A

[温度監視] ※TH1 は基板外
J5 (V3S/GND/TEMP_ADC, from P-MAIN J_TXT1)
 └ V3S ─ R6 10k 1% ─┬─ TEMP_RAW ─ J4 ─ TH1(NTC 10k B=3977, Q1 樹脂面に貼付) ─ GND
                     ├─ C5 100n → GND
                     └─ R7 1k ─ TEMP_ADC ─┬─ C6 1n (DNP)
                                           └─ J5.3 → P-MAIN
```

U1 は **A ch のみ使用**。INB(pin4) = GND、OUTB(pin5) = NC。

## 3. 電源

| 項目 | 値 |
|---|---|
| 主電源 | **V12 = 12V**（実運用は Li-ion 3S: 9.0〜12.6V）。P-PWR の `SW_TX` → `J_TX`(XT30) から供給 |
| 動作範囲（検証済） | **9V / 12V の2点**。9V で Vds=33.8V、12V で Vds=45.1V |
| ピーク電流 | **Id max = 1.66A @12V**（バースト中のタンク循環電流。定常ではない） |
| 平均電流 | バースト 20 サイクル = 100µs。ping 周期 1s なら duty 0.01% → 平均は無視できる |
| バルク | C1 470µF/25V（購入済ルビコン PX, D10 P5）。バースト中の V12 サグを吸収する主体 |
| 基準電源 | **V3S = 3.3V**（温度分圧の基準のみ）。P-MAIN の V3D を `J_TXT1` 経由でもらう。消費は 25℃ で 165µA |

> **P-PWR 側の既知の運用制約**: `SW_TX` は必ず `SW_PWR` より先に入れること。
> 運用中に投入すると C1 470µF への突入で VBAT_M が 5.13V まで落ち（電池終止 9.0V 時）、
> LXDC55 の Vin 下限 6.0V を 74µs 割る。詳細は `sim/notes.md` 2026-08-03 節 / `pcb/BRINGUP_BOARDS.md`。
> なお **「TX の C1 を 100〜220µF に下げる」対策は無効**（突入は上流の直列抵抗 0.34Ω で決まる R 制限）。
> C1 = 470µF は現行のまま維持すること。

## 4. 各段の設計値と根拠

### 4.1 ゲート駆動（U1 TC4427 / R1 / R5 / R2 / D2）

| 項目 | 値 | 根拠 |
|---|---|---|
| 入力しきい値 | TC4427 は **VIH max 2.4V** | 3.3V ロジックを**直結できる**。旧版（5V パルス必須）の制約はこれで解消 |
| 出力振幅 | **12V**（VDD = V12） | 2SK4017 の Vth = 1.3〜2.5V（データシート）に対し、最悪値でも確実にフルエンハンス |
| Vgs 実測（sim） | **12.13V** | VGSS ±20V に対し余裕 7.9V |
| R1 100Ω | 入力側直列ダンピング | TC4427 の入力容量は数 pF なので時定数 1ns 未満。波形は変わらずリンギングだけ落ちる |
| R5 10Ω | ゲート抵抗 | LTspice では TC4427 出力段を「12V スイング + Rser 7Ω」でモデル化、合計 17Ω |
| R2 10k | ゲートプルダウン | **ケーブル未接続 / 電源投入時に Q1 を確実に OFF に保つ**。TX 基板には EN 端子が無いので、この抵抗が唯一の安全側デフォルト |
| D2 GDZJ15C | 15V ツェナー | VGSS ±20V に対し 5V のマージン |

> `sim/notes.md` および `CLAUDE.md` の「実 2SK4017 の Vth 上限 4V」という記述は、
> データシート実値（**Vth = 1.3〜2.5V @VDS=10V, ID=1mA**）より保守的。判断は変わらない（12V 駆動で余裕）が、
> 数値の出典としてはデータシートを使うこと（§9-6）。

**P-MAIN 側にも同じ 100Ω（`R_TXP`）が入っている**ので、PWM 経路の直列抵抗は**合計 200Ω**。
TC4427 の入力容量に対しては依然として無視できる（時定数 < 1ns、周期 5µs の 0.02%）。

### 4.2 共振タンク（L1 + 振動子 C0）

TD04A の制動容量 **C0 = 1260pF（仮定値、LCR 実測待ち）** と L1 470µH で:

| 諸元 | 式 | 値 |
|---|---|---|
| 共振周波数 f0 | `1/(2π√(L·C0))` | **206.8kHz**（公称値） |
| L1 / C0 のリアクタンス @f0 | `2πf0·L` | 各 **611Ω**（同調しているので等しい） |
| タンクの Q | `X / ΣR`、ΣR = R3 10Ω + 振動子等価直列 100Ω + L1 DCR | **≈ 5.5**（損失はほぼ振動子の 100Ω が支配） |
| 駆動条件（LTspice） | 200kHz / on 2.4µs / 周期 5µs = **duty 48%** / 20 サイクルバースト | ファーム仕様は 10〜20 サイクル |
| 昇圧比 | Vds_peak / V12 | **3.76 倍** |

**L1 の公差が f0 を大きく振る**（§9-1）。実部品 TCV-471M-2.5A-5026 は **470µH ±20%**:

| L1 | f0 |
|---|---|
| 376µH（−20%） | 231.2kHz |
| 464µH（データシート添付の実測平均） | 208.1kHz |
| 470µH（公称） | **206.8kHz** |
| 564µH（+20%） | 188.8kHz |

RX 側 MFB BPF は f0 = 206.3kHz / Q = 2.53（−3dB 帯域 165〜247kHz）なので、
L1 が公差いっぱいにずれても**受信帯域からは外れない**。ただし TX の駆動振幅は共振ずれの分だけ落ちる。
→ **L1 は LCR で実測し、C0 実測値とペアで f0 を確定すること。**

### 4.3 保護

| 部品 | 役割 | 検証値 |
|---|---|---|
| D1 SMBJ48A（DRAIN） | **振動子が外れた/断線したとき**にタンクの C が消えてフライバック電圧が跳ね上がるのをクランプ | 故障時 Vds = **53.4V < VDSS 60V**。通常動作では不導通（TVS 電流 1.5mA） |
| D3 SMBJ15A（V12） | 電源ラインのサージ・過電圧 | — |
| D2 GDZJ15C（GATE） | VGSS 保護 | §4.1 |
| R2 10k（GATE） | 未接続時の OFF 保証 | §4.1 |
| R3 10Ω（直列） | ダンピング。振動子への突入電流制限とタンク Q の意図的な低下 | — |
| R4 100k（ブリード） | 電源切断後の残留電荷放電 | 12V 時 120µA |

### 4.4 MOSFET 温度監視（NTC 分圧）

**TH1 は基板外**。Vishay `NTCLE100E3103GB0`（10kΩ / B = 3977K）を
**Q1 の樹脂モールド面**に絶縁性熱伝導接着剤で貼り、2芯線で J4 に戻す。
**金属タブ（= ドレイン、45V が乗る）には絶対に貼らない。**

`TEMP_RAW = 3.3V × Rntc / (10k + Rntc)`（TX 基板単体・無負荷時）:

| 温度 | Rntc | TEMP_RAW |
|---|---|---|
| 0℃ | 33.9kΩ | 2.55V |
| 25℃ | 10.0kΩ | **1.65V** |
| 40℃ | 5.28kΩ | 1.14V |
| 60℃ | 2.46kΩ | 0.65V |
| 85℃ | 1.07kΩ | **0.32V** |
| 100℃ | 0.69kΩ | 0.21V |

**温度上昇で電圧が下がる**（負特性）。故障モードは両端に振り切れるので識別できる:

| 故障 | 読み値 | ファームの扱い |
|---|---|---|
| NTC 断線 | R6 が 3.3V へ持ち上げる → **≈3.3V** | レンジ外 → 送信停止 |
| NTC 短絡 | **0V** | 過熱と同じ → 送信停止 |
| ケーブル（J5）断線 | P-MAIN の `R_TTD` 100k が **0V** へ落とす | 過熱と同じ → 送信停止（フェイルセーフ） |

**なぜ温度監視が要るか**: 定常のスイッチング損失はごく小さい（duty 0.01% 級）。守りたいのは
**PWM が High 固定で止まる故障**。この場合 Q1 が連続 ON になり、電流は
`12V / (L1 DCR 0.5Ω + RDS(on) 0.07Ω)` ≒ **21A**（飽和・熱を無視した静的見積り）まで行こうとする。
2SK4017 の ID 定格 5A、L1 の IDC 2.5A をどちらも大きく超えるので、L1 か Q1 が焼ける。
NTC はこれを Q1 の温度上昇として検出する唯一の手段。

> **送信停止は `TX_PWM` を Low 固定で行う**（P-MAIN の設計）。本基板に EN 端子は無い。

## 5. 外部インターフェース

### J1 — 12V 電源入力（XT30PW-**F**、横型・基板端実装）

| pad | 刻印 | ネット |
|---|---|---|
| 1 | `−` | `GND` |
| 2 | `+` | `V12` |

配置 (57.8, 14) rot270、**開口は基板右端（+x）方向**。コートヤードは基板端 x=70 から 2.35mm 突き出す（意図的）。
接続先は **P-PWR `J_TX`（XT30PW-M）**。両端の性別が M / F なので中継ケーブルは **F—M** になる。

> **要確認（§9-3）**: 購入済みは XT30PW-**M** のみ（`pcb/datasheets/XT30PW-M_akizuki_117949.pdf`）。
> 本基板が指定している **-F は未購入の可能性がある**。
> また 12V を出す側（P-PWR `J_TX`）がオス＝ピン露出なので、通電中の短絡に注意。

### J2 — PWM 入力（JST XH 2P）

| pin | ネット | 向き | 内容 |
|---|---|---|---|
| 1 | `PWM_IN` | MCU → TX | 200kHz / duty 48% バースト。3.3V ロジックで可 |
| 2 | `GND` | — | — |

配置 (65.6, 27) rot270。接続先 **P-MAIN `J_TX1`（XH2、同順ストレート）** → `R_TXP` 100Ω → **Pico GP16**（物理21番、PWM slice0A）。

### J3 — TD04A 振動子出力（端子台 2P / 5.08mm ピッチ）

| pin | ネット | 内容 |
|---|---|---|
| 1 | `XD` | 振動子ホット。**45.7Vpp**（12V 動作時） |
| 2 | `GND` | 振動子コールド／シールド |

配置 (13, 42) rot0。シルク `XD` / `GND` あり。

### J4 — NTC 引き出し（JST XH 2P）※基板外の TH1 へ

| pin | ネット | 内容 |
|---|---|---|
| 1 | `TEMP_RAW` | NTC ホット |
| 2 | `GND` | NTC コールド |

配置 (10, 18) rot0 — **Q1 の真上**。TH1 までの 2 芯線が約 4mm で済むように置いてある。
シルク `NTC G`、および基板下端に `TH1 -> Q1 mold face, NOT metal tab`。

### J5 — 温度出力 / 3.3V 基準（JST XH 3P）

| pin | ネット | 向き | 内容 |
|---|---|---|---|
| 1 | `V3S` | MCU → TX | 3.3V 基準（分圧のみ、165µA） |
| 2 | `GND` | — | GND を**中央**に置き、3V3 と TEMP_ADC を隣接させない |
| 3 | `TEMP_ADC` | TX → MCU | DC 0.2〜2.6V、出力インピーダンス約 6kΩ |

配置 (0.5, 12) rot270。シルク `3V3` / `G` / `AD`。
接続先 **P-MAIN `J_TXT1`（XH3、同順ストレート）**: 1=`V3D` / 2=`GND` / 3=`TX_TEMP_RAW`。

> `README.md` は J5 を「3V3/TEMP_ADC/GND」と書いているが、**実際の順は 1=3V3 / 2=GND / 3=TEMP_ADC**（§9-6）。

### 親機側（P-MAIN v5.7）との整合

```
P-PWR J_TX(XT30PW-M) --XT30 F-M ケーブル--> TX J1(XT30PW-F)   : 12V
P-MAIN J_TX1 (XH2)   --XH2 ストレート-->    TX J2(XH2)        : TX_PWM_O / GND
P-MAIN J_TXT1(XH3)   --XH3 ストレート-->    TX J5(XH3)        : V3D / GND / TX_TEMP_RAW
```

| TX 側 | P-MAIN 側 | P-MAIN の処理 |
|---|---|---|
| `J2.1 PWM_IN` | `J_TX1.1 TX_PWM_O` | Pico GP16 → `R_TXP` 100Ω（ダンピング） |
| `J5.1 V3S` | `J_TXT1.1 V3D` | 3.3V デジタルレール |
| `J5.3 TEMP_ADC` | `J_TXT1.3 TX_TEMP_RAW` | `R_TT` 1k + `C_TT` 100n（τ=100µs）+ `R_TTD` 100k → Pico **GP27 / ADC1**（物理32番） |

**ファームの温度換算について（要修正の指摘、§9-4）**:
P-MAIN の `R_TTD` 100k は TX 側の出力インピーダンスに並列に効くので読み値が下がるが、
**その低下率は温度によって変わる**（TX 側テブナン抵抗 = R6∥Rntc が温度で動くため）。

| 温度 | R6∥Rntc | +直列 2k（R7+R_TT） | R_TTD 100k による低下 |
|---|---|---|---|
| 0℃ | 7.72k | 9.72k | **−8.9%** |
| 25℃ | 5.00k | 7.00k | **−6.5%** |
| 85℃ | 0.96k | 2.96k | **−2.9%** |

→ **一定係数（P-MAIN のコードコメントにある −5.7%）で補正してはいけない。**
分圧網を解いて Rntc を求め、そこから B 定数式で温度に戻すこと。

## 7. 基板物理仕様

| 項目 | 値 |
|---|---|
| 外形 | **74 × 50mm**。アウトラインは `(-4, 0, 70, 50)`（温度ブロック追加時に左へ 4mm 延長） |
| 層数 | 2層（F.Cu / B.Cu）、両面 GND ベタ |
| 最小クリアランス | 0.2mm（`build()` 既定。微細ピッチ部品なし） |
| トラック幅 | V12 幹線 1.2mm / DRAIN・XD 1.0mm / V12 支線 0.5〜0.8mm / GATE・OUTA 0.6mm / 温度系 0.5mm |
| ビア | 7個（GATE 1 / V3S 2 / TEMP_ADC 2 / GND 2） |
| 取付穴 | M3 (φ3.2) × 4 — (0, 4) / (66, 4) / (0, 46) / (66, 46)。**穴ピッチ 66 × 42mm**、基板端から全方向 4mm |
| 実装 | ほぼ全て **THT 手はんだ**。SMD は D1 / D3（SMBJ、D_SMB）の 2 点のみ |
| 実装高さ | 3D 出力上は上面 13.79mm（`pcb/3d/`）。ただし **L1 のモデルが実物と違う**ので要再確認（§9-1） |
| 配線 | **全て手配線**（`tracks` / `vias` を明示）。オートルータ未使用 |

### 配置の要点

- **高 dv/dt ノード（DRAIN / GATE）と温度監視系を分離**してある。
  温度ブロック（J5 / C5 / R6 / R7 / C6）は基板左端の縦一列（x ≈ −1.5〜1.0）、
  DRAIN / GATE は基板中央〜右。R6 / R7 は**縦立て実装（P2.54）**で省スペース化。
- J4（NTC 引き出し）は Q1 の真上に置き、TH1 までの引き回しを最短にしてある。
- `V3S` は左回り（x = −3 の B.Cu 回廊）、`TEMP_ADC` は右回り（x = 8 の B.Cu 回廊）で、
  TEMP_RAW の縦スパイン（x = −1.5）を跨がせている。B.Cu 同士も交差しない。
- Q1 のソースパッドと U1 の GND ピンには、GND ベタのサーマル孤立を防ぐスタブを明示的に引いてある。

### ⚠ 45.1V という数字が乗っている前提

**Vds = 45.1V は暫定値**。48V 枠に対する余裕が 2.9V（6%）しかないうえ、以下の 2 つの仮定の上に立っている:

1. **C0 = 1260pF（TD04A の制動容量、仮定値）** — LCR 実測待ち。C0 が変われば f0 も振幅も動く。
2. **L1 の LTspice モデルは `Rser = 2Ω`** — 実部品の DCR は **0.5Ω（実測 0.389Ω）** なので
   **モデルは損失を過大評価している**＝実機は 45.1V より高く出る。
   単一直列ループ近似での見積りは Q が 5.46 → 5.53（+1.3%）、Vds ≒ **45.7V** 程度。
   桁が変わる話ではないが、6% の余裕に対しては無視できない。

→ **C0 と L1 を LCR で実測し、`.param C0` / `Ltune` / L1 の `Rser` を実測値に置き換えて再実行するまで、
45.1V は確定値として扱わないこと。**

- L1 の飽和挙動（1.66A ピークは IDC 2.5A 以内だが、トロイダルコアの実飽和特性は未確認）

## 9. 既知の課題 / TODO

### 1. ★ L1 のフットプリントが実物と合わない（最優先・要設計変更）

購入済みの実部品は **秋月 [113382] トロイダルコイル `TCV-471M-2.5A-5026`**
（`pcb/datasheets/Toroidal_L_TCV-471M-2.5A-5026_akizuki.pdf`）:

| 項目 | 実物（データシート） | 現在の KiCad FP `Inductor_THT:L_Radial_D10.0mm_P5.00mm_Fastron_07M` |
|---|---|---|
| 外径 A | **16.0mm max**（実測平均 14.95mm） | 胴体 φ10.0mm |
| 高さ B | 8.0mm max（実測平均 7.20mm） | — |
| **リード間隔 C** | **10.0 ± 2.0mm** | **パッドピッチ 5.00mm** |
| リード線径 D | 0.45mm | — |
| L / RDC / IDC | 470µH ±20% / 0.5Ω max / 2.5A | — |

**深刻なのは胴体側**:

- **ピッチ（10mm → 5mm）は吸収できる。** リードは 0.45mm の単線で、しかも公差が ±2.0mm
  （= 曲げて合わせる前提の部品）。片側 2.5mm ずつ内側に曲げれば現在のパッドに挿さる。
  ただし正攻法は専用 FP を作ること。
- **★胴体が干渉する（これが実質のブロッカー）。** φ15〜16mm の胴体は現在の配置
  （中心 (21.5, 10)）だと x[13.5, 29.5] / y[2, 18] を占める。
  **J4（NTC コネクタ、コートヤード x[7.02, 15.47] y[15.12, 21.92]）と重なる。**
  現 FP のコートヤードは x[16.22, 26.77] y[4.72, 15.28] しかないので、DRC は通ってしまう。

→ **対応 = 自作 FP（`footprints/AquaBeacon.pretty/`）+ L1 周辺の再配置 + 再ビルド + 3D モデル差し替え。**
本仕様書の範囲外なので、着手前にユーザーの承認を取ること。
なお `pcb/README.md` が書いている **Bourns RLB0912-471KL は TX_advanced 用**であり、本基板の実部品ではない。

### 2. C0 = 1260pF が未実測（`CLAUDE.md` の確定事項）

TD04A の LCR 実測 → f0 再確定 → 必要なら L1 の選別、RX 側 MFB の f0 追従。
L1 自体も ±20% 公差（188.8〜231.2kHz）があるので、**L1 と C0 はペアで実測して組み合わせる**のが正しい手順。

### 3. XT30 の性別と購入状況

本基板 J1 = **XT30PW-F**、P-PWR `J_TX` = **XT30PW-M**、購入済みデータシートは **-M のみ**。
-F を実際に持っているか、`../docs/未踏ジュニア購入物品.xlsx` で要確認（Excel は無断で書き換えない）。

### 4. TX 温度の換算式（ファーム側）

P-MAIN のコードコメントにある「読み値 −5.7%、一定補正」は 2 点で不正確:
- 同コメント自身が言う「テブナン 5k + 直列 2k」で計算すると **−6.5%**（−5.7% は直列 1k 分の計上漏れと思われる）
- そもそも**低下率は温度依存**（0℃ −8.9% / 85℃ −2.9%）。一定係数では補正できない

→ ファームは分圧網を解いて Rntc を出すこと（§5）。P-MAIN 側のコメントも要訂正。

### 7. 振動子に DC バイアスが掛かっている（未検証の指摘）

`XD` は `R3` 10Ω 経由で `DRAIN` に**直流的に繋がっている**（DC ブロックコンデンサが無い）ため、
通電中は振動子に常時 **約 12V の DC** が印加される（`R4` 100k 経由で 120µA）。
TD04A の耐圧・分極への影響は未確認。実害があるなら XD 直列に DC ブロック（例: 0.1µF/100V）を
入れることになるが、それはタンク定数に影響するので**入れるなら LTspice で再検証が必要**。
