# PARENT_PWR (P-PWR) 部品一覧

親機電源基板で**実際に使う部品**と、その仕様(データシート・CAD図・寸法図・ピン配置)への
リンク集。回路設計・部品配置・定数決めの前に、必ずここのリンク先で
**ピン配置 / 外形寸法 / 電気特性**を確認すること。

- 対応生成スクリプト: `pcb/build_parent_pwr.py`
- 基板バージョン: **P-PWR v1.2**(2026-07-31 `J_I2C` を XH4→**XH5** にして INA226 の ALERT を同居させ、別建ての `J_ALT`(PH2) を廃止＝C-PWR `J_I2C` と完全同一ピン順(V3S/GND/SDA/SCL/INA_AL)。P-MAIN `J_I2CP` とストレート5芯で繋がる。**ガーバー/BOM/CPLは要再出力** / 旧 v1.1=2026-07-24 / 100×84mm(カメラBUCK追加で70→84拡張) / min_clearance=0.13mm(MSOP-10対応, JLC 5mil可))
- ネット定義の正: `pcb/SPEC_MAIN_PWR_2026-07-19.md`
- 検証記録: `sim/notes.md`(2026-07-23 LTspice 全PASS: 突入40A/TXバーストサグ0.089V/逆接遮断/F1速断必須/C_BLK100µ。MYMGKはVin窓8〜15VでLiPo3S適合→再検証不要)
- **実装区分**: **基板上のSMD部品は全て JLCPCB の SMT 実装に出す**(2026-08-03 方針変更)。
  ただし本基板は受動部品がまだTHT(軸抵抗`R_G`/`R_LED`、ディスク/電解C、砲弾LED)なので、
  SMD なのは4点だけ = `U_INA`(INA226 MSOP-10) / `R_SH`(20mΩ 2512) / `C_VS`(100n 0603) /
  `D1`(SMBJ15A SMB, **C19077569 = Preferred 装着費無料**。単方向TVS＝向きあり)。
  正は `pcb/jlc_export.py` の `JLC_PARTS['PARENT_PWR']`、出力は `PARENT_PWR_bom_jlc.csv`(4行) /
  `PARENT_PWR_cpl_jlc.csv`(4点)。
  💡 CHILD_PWR と同様に受動部品をSMD化すれば手はんだをさらに減らせる(要 再配置・再配線。未実施)。
  他は購入済部品の手はんだ(SMB TVS含む)。

> **記入ルール**: 1部品につき**リンクを最低1つ**(できれば ①データシート/寸法図 ②CAD/3Dモデル
> ③購入ページ の3種)。CAD図・機械寸法のある一次資料(メーカー公式)を優先。(CLAUDE.md参照)
