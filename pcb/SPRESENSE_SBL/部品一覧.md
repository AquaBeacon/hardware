## 公式HTMLで確認できたSMC20D17H5の値

- 外径20mm、内径17mm、高さ5mm。電極は内周面と外周面。
- 径方向共振57kHz±2kHz、静電容量2400pF±15%（1kHzでの測定）。
- 共振インピーダンスは **12Ω以下**。12Ωを最低負荷抵抗に使ってはいけない。
- 水中通信・送受信の用途記載はあるが、完成品の耐水深、駆動電圧上限、
  水中TVR/RVS曲線、防水後の帯域・位相特性は今回確認できていない。
- 価格は2個セット32.84米ドル（調査日表示、税・国際送料等は別、未発注）。

## SPRESENSE側の確認済み端子

公式拡張ボード回路図p7を画像で確認した。これは**既製ボードの端子表**で、
未設計の自作基板に対応するネットリストではない。

| 用途案 | 拡張ボード JP10 | 注意 |
|---|---|---|
| RX A | 10 = MIC_A | 内部へ1uFでAC結合 |
| RX B | 9 = MIC_B | 同上 |
| RX C | 4 = MIC_C | 同上 |
| TX波形監視 | 3 = MIC_D | アンプ出力を直結しない。分圧・保護・AC結合の検証が必要 |
| 音声GND | 7 / 8 / 13 / 14 | AGND_MICに接続。pin1/15のGND_PHとの区別を確認 |
| 使用しない | 2、5、6、11、12、16 | UART_SEL、BIAS、DMIC_CLKを音声入力と取り違えない |

[ピン番号確認画像](research/JP10_pinout.png)。本体GPIOは1.8V系、拡張ボードのGPIO電圧設定と
音声入力の許容振幅は別の仕様。マイクバイアス抵抗の実装状態も現物で確認する。
マニュアルp35の入力フルスケールはAVDD_MIC/2 **Vpp（typ）**で、3.3V GPIO入力とは異なる。
