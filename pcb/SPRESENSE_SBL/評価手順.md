# SBL振動子とSPRESENSEの評価手順

本手順は未実施。空欄を実測値で埋めてから設計へ進む。
20m通信・位置誤差10cm以下は受入目標であり、現在の達成値ではない。
10cmは当面「SBL座標系の3D位置誤差の95パーセンタイル」と解釈する。
この統計定義・初期評価領域は設計側の提案で、全方向の最大誤差保証とは異なる。

## 0. 最初に揃える情報・道具

- SMC20D17H5の最新定格書／メーカー回答。問い合わせ下書きあり。
- 評価用2個。追加個数は最初の水中応答を確認してから決める。
- 小信号周波数掃引のできる信号発生器、2チャネル以上のオシロスコープ、
  既知の非誘導性直列抵抗、LCRメータ（可能ならインピーダンスアナライザ）。
- 録音用SPRESENSEと公式拡張ボード。ゲイン固定で全チャネルの生PCMを残す。
- シールドケーブル、寸法固定治具、温度計。塩水では塩分・音速評価も行う。
- メーカーが素子・電極に適合を確認した封止材と加工条件。

信号発生器の表示電圧は50Ω終端時と開放時で異なることがある。
**駆動値は必ず振動子端子で測定**する。メーカー許容値を確認するまで送信用の高電圧を決めない。
SPRESENSEのヘッドホン出力へ圧電素子を直接つなぐ構成は未検証。

## 1. 電気的特性

裸素子の個体ID、寸法、電極、容量、測定温度・測定器・測定信号条件を記録する。
防水加工後・ケーブル接続後も同じ条件で測る。容量だけで共振負荷を決めない。

複素インピーダンスは既知直列抵抗Rsを用い、共通GNDに対する発生器側Vsrcと
振動子側Vdutの複素振幅から求める：`Z = Rs * Vdut / (Vsrc - Vdut)`。
位相も取得する。位相のないVpp比だけから複素等価回路を作らない。
プローブ容量・直列抵抗の周波数特性・ケーブルを含めて補正する。
フルブリッジ出力をGND基準のプローブで短絡しない。橋絡出力の場合は適切な差動測定が必要。

初回は20〜80kHzを探索し、共振付近を細かく測る。
これは試験範囲であり使用帯域の決定ではない。駆動信号は定格確認済みの小信号条件を用いる。
最小|Z|・位相・共振点・反共振点・損失を保存し、その後にBVD等価回路をフィットする。
公式の「Zm ≤12Ω」からRmot=12Ωと設定して、電流上限が安全と判定しない。

## 2. 防水と水中応答

銀電極を水へ露出させず、気泡・剥離・ケーブル取り出し部の漏水を評価する。
一般の接着剤で被覆しただけで任意の水深に耐えるとみなさない。
裸セラミックの外径は防水後の外形ではない。厚み・拘束・ケーブルは特性を変える。
使用水深は未確定なので、耐水深を資料に書き込まない。

同じ送信素子と同じ位置関係で、受信側だけを交換して各個体の振幅・位相を比較する。
送信側端子電圧を同時に測って正規化し、プリアンプ利得・ケーブル・記録ゲインを固定する。
結果は `V受信 / V送信端子` の伝達特性であり、絶対RVSやTVRではない。
送受信感度を分離するには校正済みハイドロホン、相互校正、またはメーカー校正データが要る。

水槽内の連続正弦波は反射で定在波ができ、振動子の帯域と水槽の特性を混同しやすい。
直接波を分離できる大きさ・配置の水槽または水域で、時間窓を切ったバースト測定を行う。
到来時刻と最初の反射の間に必要な観測窓を確保できなければ、その測定から自由音場の帯域を確定しない。
同一位置・同一距離に交換できる治具を使い、位置誤差を素子の群遅延差と解釈しない。

### 実測CSV

`research/measured_sweep_template.csv` はヘッダーだけの空テンプレート。
**合成データを実測欄へ入れない。** 周波数グリッドは全個体で揃え、20〜80kHz内、刻み100Hz以下。
複素伝達特性を求めた方法・飛行時間・位相補正・ノイズ測定帯域を測定ノートへ残す。

| 列 | 単位・意味 |
|---|---|
| unit_id | 防水後の受信素子を識別するID |
| frequency_hz | 測定周波数Hz |
| z_real_ohm / z_imag_ohm | 同個体の端子で測った複素インピーダンスΩ |
| transfer_real / transfer_imag | 同一送信器・位置で得たV受信/V送信端子の複素比 |
| tx_vrms | 実際の送信端子Vrms。発生器の設定値ではない |
| noise_vrms | 同じ受信系・帯域で送信なしの雑音実効値V |
| noise_bandwidth_hz | 上記の雑音測定帯域Hz。全データで同じ値を使う |

```powershell
python -X utf8 sim\sbl_transducer_evaluate.py pcb\SPRESENSE_SBL\research\measured_sweep.csv
```

出力は `.assessment.json`。共通-6dB帯域・同じ雑音帯域でのSNR・相対群遅延を算出する。
暫定条件は共通帯域8kHz以上、測定条件でSNR10dB以上。
距離が短い試験のSNRを20mに外挿して合格させない。
ゲイン差と固定遅延を校正しても、帯域内で変動する位相差・温度変化は残るため別途評価する。
100Hz以下の刻みでも位相ラップの一意性は自動保証されず、既知の短い相対遅延となる治具で確認する。
このツールは駆動許容電圧・20m通信・10cm測位をPASSにしない。

## 3. SPRESENSE電気試験

公式JP10の割当は [部品一覧](部品一覧.md) に記載済み。
音声入力へ直接3.3Vロジックや送信パワー段を接続しない。
電圧制限・AC結合を確認した既知入力を用い、ゲイン0dBから評価する。
SPRESENSEのマイクバイアス抵抗は現物実装状態を確認する。
ICのtypフルスケール値を絶対最大定格とみなさない。

確認項目：

1. 4ch/192kHzの実データ取得。チャンネル順を既知信号で確認する。
2. 20〜80kHzの実周波数応答。192kHzというサンプル周波数だけで80kHzまで使えるとしない。
3. 同じ信号を分配したときの振幅差・群遅延差・遅延変動。チャンネル間クロストークも測る。
4. 全チャネルでゲイン固定、AGCや自動処理を停止。設定値と校正データを対にする。
5. 録音サンプル数の連続性、SDKのオーバーフロー通知、SD書込みの最悪時間を記録する。
6. 連続録音中に送信してTX監視波形と受信波形を同じサンプル列で得られること。
   一般のRecorder/Playerの切替で実送信基準が失われる構成は採用しない。
7. 大きい送信監視入力が他チャネルへ漏れないこと、受信前段の飽和から応答前に復帰すること。

データ量：4ch/192kHzで16bit PCMは1.536MB/s、24bit packedは2.304MB/s、
int32格納は3.072MB/s。平均処理速度だけでなく、バッファ余裕を評価する。
チャネル同時取得は共通クロックを使える利点があるが、校正なしのサブus一致を意味しない。

## 4. 往復測距と複数ノード

親機TX電気波形の時刻基準から子機応答を測る。
子機が返す受信〜実送信の応答遅延と、送受信回路・振動子の遅延を除去する。
中心同士が同位置の理想化では、おおよその距離は `c*(往復時間-応答遅延-校正遅延)/2`。
正確な解では親機TX位置、各RX位置、子機TX/RX間のオフセットを用いる。
単純なコールバック時刻・USB受信時刻を距離計算へ代入しない。

20mの音の往復だけで約26.67ms（音速1500m/s仮定）。
スロットはこれにチャープ長・データ長・子機処理・リングダウン・反射のガードを加えて決める。
実測前に更新レートを保証しない。親機が一つずつ子機IDを呼び、期限切れ応答を捨てる。
双方向の上下チャープなどでドップラーと整合性を検査する。
物理波形・パケット・ファームウェアはまだ実装済みではない。

## 5. 最終受入試験

測定距離・角度・深度・温度・塩分・送信電力・ノードID・生波形を記録する。
SBLアレイ中心からの真値を独立した方法で測る。
静止で数条件、次に移動・複数ノード・反射が強い条件へ広げる。

- 初期対象：距離5/10/20m、法線付近と30度方向、アレイ水中側。
- 各条件で連続100回以上を初期試験とする。これは稀な外れ値を保証する試験数ではない。
- 暫定目標：有効測位率95%以上、有効測位の3D位置誤差P95が10cm以下。
  欠測・外れ値・無効判定の数を全送信数に対して報告し、良い結果だけ抽出しない。
- 60度以上も測るが、初期30度以内での合格を全角度へ拡張して報告しない。
- 基線の実測、温度・塩分に基づく音速、送受信遅延校正後でも残る系統誤差を加えて判定。
- 20mでのSNR不足、共通帯域不足、反射による誤検出、校正ドリフトを別項目で記録。

不合格なら、まず帯域・感度・指向性と校正のどこが原因かを分ける。
未知の許容電圧を超えて駆動を強めて解決しない。
必要ならSMC25D22H12PLS、校正済みの既製品、アレイ配置、直接波推定方式を再比較する。
