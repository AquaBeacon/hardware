## B. 設計の要判断(ユーザ判断待ち。今は動く)

- [ ] **P-MAIN ↔ P-PWR のコネクタ1本化**。子機は XH9 1本に統合済みだが、親機は
      `J_MAIN`(XH6) + `J_I2C`(XH5) = 11ピン2本のまま。P-MAIN の V5D/V3D 負荷は各0.2A程度で
      倍ピンは不要なので XH7 1本にできる。ただし **P-PWR は手配線(tracks=list)なので
      配線を書き直す必要があり、2基板とも再レイアウトになる**。密閉容器内のケーブルが
      1本減る価値と天秤にかけて判断する。
- [ ] **BNO085 の PS0/WAKE を GPIO へ**(C-MAIN)。CEVA 1000-3927 §1.2.4 note5 は
      「Pin6(PS0/WAKE) must be connected to a GPIO」としている。v4.1 で GP7/GP9 が空いたので
      「Pico に空きが無い」という理由はもう成立しない。**ただし配線が極めて難しい**:
      GP7/GP9 はどちらも Pico 東列で BNO は基板北端、BNO 下列パッドの隙間は 0.84mm、
      途中で I2C 幹線(B.Cu)と V3A 幹線(F.Cu)の両方を跨ぐ。加えて Adafruit 4754 の RST に
      プルアップがあるか未確認(無ければ P0 にも 10k プルアップが要る)。
      **現状(P0=V3D 固定)は Adafruit 公式ライブラリと同じ構成で実動作する**ので緊急性は低い。
      やるなら単独の改版で。詳細は `build_child_main.py` の docstring。
