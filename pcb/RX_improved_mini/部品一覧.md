# RX_improved_mini 部品一覧

受信基板で**実際に使う部品**と、その仕様（データシート・寸法図・ピン配置）へのリンク集。
回路設計・部品配置・定数決めの前に、必ずここのリンク先で
**ピン配置 / 外形寸法 / 電気特性**を確認すること。

- 対応生成スクリプト: `pcb/build_rx_improved_mini.py`
- 回路仕様: **[基板仕様書.md](基板仕様書.md)**
- 基板バージョン: **RX_improved_mini v1.1**（68 × 46mm / 2層 / R・C は 0805 SMD、IC・ダイオード・トリマは THT）
- ローカル保存済み PDF: `pcb/datasheets/`

> **記入ルール**: 1部品につきリンクを最低1つ（できれば ①データシート/寸法図 ②CAD/3Dモデル
> ③購入ページ の3種）。メーカー公式など一次資料を優先。リンクは実在確認済みのもののみ。

## 1. 能動部品（THT）

### NJM2137D　2回路入 高速・超広帯域オペアンプ　（`U1`, `U2` / DIP-8）

- **役割**: U1A = 初段増幅、U1B = MFB バンドパス、U2A = 後段増幅、U2B = 未使用（ユニティバッファ）
- **KiCad**: シンボル `Amplifier_Operational:TL072`（ピン配置互換）/ FP `Package_DIP:DIP-8_W7.62mm`
- **要注意**: **非レール・ツー・レール**。V±=±2.5V / RL=1kΩ で VOM = +1.4V typ / −1.2V typ
  → 3.3V 単電源ではレールから約 1.1V のヘッドルームを失う。これが ENV 振幅の上限を決めている（仕様書 §4）
- 入力同相範囲 = (V−)+1.3V 〜 (V+)−1.3V → 3.3V 時 **1.3〜2.0V**。VMID = 1.65V は範囲内だが余裕は ±0.35V のみ
- GBW 200MHz / fT 40MHz / SR 45V/µs / ICC 1.14mA typ / 動作電圧 ±1.35〜±6V

### LM393GN　2回路入 コンパレータ　（`U3` / DIP-8）

- **役割**: U3A = 包絡線しきい値比較（ENV vs VTH）、U3B = 未使用（+IN:GND / −IN:V3A → 出力 Lo）
- **KiCad**: シンボル `Comparator:LM393` / FP `Package_DIP:DIP-8_W7.62mm`
- **オープンコレクタ出力** → 基板上で R18 10k を V3A へプルアップ済み。マイコン GPIO に直結可
- 単電源 2〜30V 動作 / 入力同相範囲 **0V 〜 VCC−1.5V**（3.3V 時 1.8V）/ 応答 1.3µs / IIB 25nA typ

### 1N4148　小信号高速スイッチングダイオード　（`D1`, `D2` / DO-35）

- **役割**: 入力レールクランプ（D1: ST1_INP → V3A、D2: GND → ST1_INP）。BAV99 相当を 2 個で構成
- **KiCad**: シンボル `Device:D` / FP `Diode_THT:D_DO-35_SOD27_P7.62mm_Horizontal`。**pin1 = K / pin2 = A**
- 過大入力 5V 時のクランプ電流は R1 100Ω により 9.5mA（連続定格 200mA に対し十分）

### BAT43　ショットキーバリアダイオード　（`D3` / DO-35）

- **役割**: 包絡線検波（アノード = DET_IN、カソード = ENV）
- **KiCad**: シンボル `Device:D_Schottky` / FP `Diode_THT:D_DO-35_SOD27_P7.62mm_Horizontal`。**pin1 = K / pin2 = A**
- **VF = 0.26〜0.33V @ IF = 2mA**（本回路の検波電流は µA〜数百µA なので VF ≈ 0.2V）→ ENV から差し引かれる
- VRRM 30V / IF 200mA / trr 5ns / Ctot 7pF。低 VF が要件なので**汎用 Si ダイオードへの置換は不可**

## 2. 可変抵抗・コネクタ・機構（THT）

### Bourns 3362P-1-104　半固定ボリューム 100kΩ [104]　（`RV1`, `RV2`）

- **役割**: 各段のゲイン調整。**レオスタット接続**（ワイパと片端を短絡）で 0〜100kΩ
  → G = 1 + (5.1k + 0〜100k)/1k = **×6.1〜×106**
- **KiCad**: シンボル `Device:R_Potentiometer` / FP `Potentiometer_THT:Potentiometer_Bourns_3386P_Vertical`
  （3362P は 3386P **縦型と互換パターン**: pin1–3 間 5.08mm、pin2 が 2.54mm オフセット、ドリル 0.8mm）
- ⚠ **RV1 と RV2 で短絡している端子が逆** → 同じ向きに回すと利得が逆方向に動く（仕様書 §7）
- シルク: RV1 = `G1`（初段）、RV2 = `G2`（後段）
