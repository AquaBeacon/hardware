# RX_improved_mini 基板仕様書

200kHz 水中音響ビーコン (TD04A) の**受信基板**。振動子の微小電圧を増幅・帯域制限し、
包絡線検波してから比較器でデジタルエッジ化する。マイコン (Pico 2 W) へは
「検出エッジ」と「包絡線振幅」の2系統を返す。

- 生成スクリプト: **`pcb/build_rx_improved_mini.py`**（このファイルが唯一の真実。`.kicad_sch` / `.kicad_pcb` は直接編集しない）
- 回路トポロジ: `pcb/build_rx_improved.py` (RX_improved v1.1) と**同一**。本基板はその小型 / SMD 混載版
- LTspice: `LTspice/RX_improved.asc`、検証 `sim/rx_improved_verify.py`、記録 `sim/notes.md`
- 部品と一次資料リンク: **[部品一覧.md](部品一覧.md)**
- 版数: **v1.1 mini**（2026-07-19 小型化 / 2026-07-26 本書作成）

## 1. 信号チェーン

```
J1 (TD04A)
 └ XD_IN ─[R1 100Ω]─ RC1 ─[C1 100n]─┬─ ST1_INP
                                     ├─ D1 1N4148 → V3A   (正側クランプ +3.3+0.7V)
                                     ├─ D2 1N4148 → GND   (負側クランプ −0.7V)
                                     └─ R2 100k → VMID    (バイアス 1.65V)
   │
   ├─ U1A NJM2137  非反転増幅  G1 = 1 + (R4 5.1k + RV1 0〜100k) / R3 1k = ×6.1〜×106
   │     └ C2 1µ が R3 と直列 → DC 利得は ×1（オフセット増幅を防ぐ）
   │
   ├─ U1B NJM2137  MFB バンドパス  f0 = 206.3kHz / Q = 2.53 / G = ×1.95
   │     R5 1k(入力) / R6 180(接地) / R7 3.9k(帰還) / C3 = C4 = 1n C0G
   │
   ├─ U2A NJM2137  非反転増幅  G2 = 1 + (R9 5.1k + RV2 0〜100k) / R8 1k = ×6.1〜×106
   │
   ├─ 包絡線検波   C6 100n → DET_IN (R10 10k で 0V 復元) → D3 BAT43 → ENV
   │     ENV 側リザーバ: C7 + C13 = 1n×2 = 2n、放電 R11 10k
   │
   ├─ ENV_ADC  = ENV × R13 / (R12 + R13) = ENV / 2        → J2.4 → マイコン ADC
   │
   └─ U3A LM393 比較器（オープンコレクタ）
         +入力 (pin3) = **ENV**（分圧前）
         −入力 (pin2) = VTH ← R15 10k + C8 100n ← TH_PWM（マイコンの PWM を平滑）
         R14 1M で +入力へ正帰還（ヒステリシス ≈ 22mV）
         R18 10k で V3A へプルアップ → CMP_OUT (3.3V 論理) → J2.6
```

未使用回路: **U2B** = ユニティゲインバッファ（+IN = VMID、OUT–IN 直結）、
**U3B** = +IN:GND / −IN:V3A（出力は常時 Lo、OC なので開放）。どちらも発振防止の定石処理。

## 2. 電源

| 項目 | 値 |
|---|---|
| 供給レール | **V3A = 3.3V**（アナログ専用）。C-PWR の `NJU7223F33`(REG3A) → コネクタ `J_RXA` から供給 |
| 消費電流（実測前の見積） | NJM2137 1.14mA typ × 2 + LM393 0.4mA typ + R18 プルアップ 0.33mA(出力Lo時) + VMID 分圧 16.5µA ≈ **3.1mA typ / 4.5mA max** |
| VMID | R16 / R17 = 100k:100k → **1.65V**、C9 10µ で低インピーダンス化（206kHz で 0.08Ω） |
| デカップリング | C10 (U1) / C11 (U2) / C12 (U3) = 100n を各 IC 直近に配置 |

> Pico の 3V3 出力からは取らないこと。デジタル系のスイッチングノイズが 60〜87dB の利得で増幅される。

## 3. 各段の設計値と根拠

### 3.1 入力保護 (R1 / D1 / D2)

- R1 100Ω がクランプ電流を制限。入力 5V 印加時、ST1_INP は −0.75〜+4.05V に収まり、
  クランプ電流は (5 − 4.05)/100 = **9.5mA**（1N4148 連続定格 200mA に対し十分）。
- TD04A から見た入力インピーダンスは実質 R2 100k（C1 は 206kHz で 8Ω）。
  TD04A の制動容量 C0 = 1260pF 想定の等価内部インピーダンス ≈ 613Ω に対して十分高く、
  **電圧受け（開放電圧を取りに行く）構成**。
- 高域通過コーナー: C1 100n × R2 100k → **15.9Hz**。信号帯域には影響しない。

### 3.2 MFB バンドパスフィルタ (U1B)

多重帰還（Multiple Feedback）型。C3 = C4 = C = 1nF、R5 = 1k、R6 = 180Ω、R7 = 3.9k。

| 諸元 | 式 | 計算値 | LTspice 実測 |
|---|---|---|---|
| 中心周波数 f0 | `1/(2πC)·√((R5+R6)/(R5·R6·R7))` | **206.3kHz** | 206.5kHz |
| Q | `0.5·√(R7(R5+R6)/(R5·R6))` | **2.53** | — |
| f0 での利得 | `R7/(2·R5)` | **×1.95 (+5.8dB)** | — |
| −3dB 帯域 | `f0/Q` | 81.6kHz | 78.5kHz |

**C0G(NP0) 必須**（C3 / C4）。X7R では容量の電圧・温度係数で f0 が動く。
TX 側の直列共振 206.8kHz と 0.24% で一致させてある。

### 3.3 利得配分と入力ダイナミックレンジ

全体利得 = G1 × 1.95 × G2。

| トリマ設定 | 全体利得 | クリップしない入力振幅（出力 1.05Vpk 基準） |
|---|---|---|
| 最小 (×6.1 / ×6.1) | ×72.6 (37.2dB) | 14.5mVpk |
| 設計基準 (×21 / ×25) | ×1024 (60.2dB) | 1.0mVpk ← LTspice 検証条件 |
| 最大 (×106 / ×106) | ×21,950 (86.8dB) | 48µVpk |

- NJM2137 の fT = 40MHz（データシート 40dB 条件）より、G = ×106 時の閉ループ帯域は約 380kHz。
  206kHz では約 −1dB / 位相 −29° になるが、実用上の破綻はない。
- 参考（未実測の見積）: 入力換算雑音 ≈ 10nV/√Hz × √78.5kHz ≈ **2.8µVrms**。
  R2 100k の熱雑音は TD04A の低インピーダンス (613Ω @206kHz) で分圧され 0.25nV/√Hz 相当に落ちるので支配的でない。
  最大利得時の実用下限は雑音の 3 倍として **約 8µVrms**。

### 3.4 包絡線検波

- **時定数（放電）**: `(R11 ∥ (R12+R13) ∥ R14) × (C7+C13)` = (10k ∥ 20k ∥ 1M) × 2n = **13.2µs**
  - `sim/notes.md` の「τ = 20µs」は R11 10k × 2n のみを見た値。実際は **ADC 分圧 R12+R13 = 20k が並列に効いて 13.2µs に短くなる**。
- キャリア 1 周期 (4.85µs) あたりの垂下 = 1 − exp(−4.85/13.2) = **31%**。
  → **CMP_OUT はバースト中 200kHz で断続する**（ヒステリシス 22mV では抑えきれない）。
  先頭エッジで飛行時間を取る用途（GP2 の PIO 入力）では問題にならず、むしろキャリア数が数えられる。
  「バースト全体を 1 発の High」で受けたい場合は C7 + C13 を 4.7n 以上へ。
- バースト長は 10〜20 サイクル = 50〜100µs（詳細設計書 §）。τ = 13.2µs は追従・消失とも十分速い
  （バースト終了 30µs 後に 10% まで減衰 → 多重エコーの分離に有利）。

### 3.5 比較器 (U3A LM393)

| 項目 | 値 | 根拠 |
|---|---|---|
| 入力同相範囲 | 0V 〜 VCC − 1.5V = **1.8V** @3.3V | LM393 データシート。ENV / VTH ともこの範囲内 |
| 出力 | オープンコレクタ + R18 10k プルアップ → **0 / 3.3V** | Pico GPIO へ直結可 |
| ヒステリシス | ΔVout × Zs/(R14 + Zs) = 3.3 × 6.67k/1.007M ≈ **22mV**（ENV ノード換算） | Zs = R11 ∥ (R12+R13) = 6.67k |
| 応答時間 | 1.3µs（100mV ステップ / 5mV オーバドライブ） | 包絡線 τ = 13.2µs に対し十分速い |
| しきい値 VTH | = 3.3V × PWM duty（R15 10k / C8 100n、τ = 1ms） | 下記 §5 |

## 4. 信号レベル ― ENV / ENV_ADC がなぜ小さいか

**ENV の上限を決めているのは NJM2137 の出力スイング（非レール・ツー・レール）である。**

| 段階 | 内容 | 値 |
|---|---|---|
| ① U2A 出力の正側スイング | NJM2137 は非 RRO。データシート VOM (V±=±2.5V, RL=1kΩ) = **+1.4V typ / +1.1V min** → レールからのヘッドルーム 1.1V (typ) / 1.4V (min)。3.3V 単電源に外挿すると Vout_max = 3.3 − 1.1 = **2.20V** | VMID 1.65V から **+0.55V** |
| ②（緩和）実負荷は軽い | 実際の U2A 交流負荷は R10 10k ∥ 検波段 ≈ 5〜10kΩ で、データシート条件 1kΩ より軽い → スイングは広がる。LTspice はレール 0.6 / 2.7V を仮定 | **+1.05V** |
| ③ BAT43 の順方向電圧 | VF = 0.26〜0.33V @ IF = 2mA。検波電流は µA〜数百µA なので **VF ≈ 0.2V** | **−0.2V** |
| ④ **ENV（検波出力ピーク）** | ① or ② から ③ を引く | **約 0.35 〜 0.85V**（LTspice 実測 **0.73V**） |
| ⑤ **ENV_ADC** | ENV × R13/(R12+R13) = **ENV / 2** | **約 0.18 〜 0.43V** |

つまり ENV_ADC が小さい理由は 2 つの掛け算:

1. **オペアンプが 3.3V 単電源でレールまで振れない**（片側 1.1V 前後のヘッドルームを失う）
2. **その上でさらに R12 / R13 で 1/2 に分圧している**

結果、Pico の 12bit ADC (0〜3.3V, 0.8mV/LSB) のうち **5〜13% しか使えていない**。

### コンパレータに入る信号は 0〜0.25V ではない

**違う。比較器の +入力 (U3 pin3) は分圧前の `ENV` に直結している。**
R12 / R13 の分圧は ADC へ向かう枝だけに効く。

| ノード | 振幅 |
|---|---|
| `ENV`（→ U3A +入力、R14 ヒステリシス、R12 分圧の入口） | **0 〜 約 0.85V** |
| `ENV_ADC`（→ J2.4 → マイコン ADC のみ） | **0 〜 約 0.43V** |
| `VTH`（→ U3A −入力）| ENV と同じ土俵で設定する必要がある → **0 〜 0.85V** |

したがって **しきい値 TH_PWM の実用 duty は 0 〜 約 26%**（3.3V × 0.26 ≈ 0.85V）。
比較器の分解能を確保するため、PWM は wrap ≥ 1000 を推奨（後述）。

### 改善提案（未適用・要判断）

`R12 / R13 の分圧をやめて ENV を直接 J2.4 へ出す`と、次の 3 つが同時に良くなる:

- ADC のフルスケール利用率が 2 倍（5〜13% → 10〜26%）
- 包絡線の時定数が 13.2µs → 20µs に戻り、キャリアリップルが 31% → 22% に減る
- 部品が 2 点減る

ENV 最大 0.85V は Pico ADC の 0〜3.3V 入力に対して安全側なので、保護目的の分圧は不要。
ADC 側から見たソースインピーダンスは R11 = 10kΩ（RP2350 の推奨上限付近だが、
C7 + C13 = 2n がリザーバとして効くので実用上は問題ない見込み。**要実測**）。
それでも足りなければ、根本策は**アナログ電源を 5V に上げる**（NJM2137 は 2.7〜12V 動作）。

## 5. 外部インターフェース

### J1 — TD04A 振動子入力（ターミナルブロック 2P / 5.08mm ピッチ）

| pin | ネット | 内容 |
|---|---|---|
| 1 | `XD_IN` | TD04A ホット |
| 2 | `GND` | TD04A コールド／シールド |

配置 (6, 26) rot90。**電線は基板左端 (−x) 方向に出る**。シルク `XD` / `GND` あり。

### J2 — マイコン接続（JST XH 6P ベース / 2.5mm ピッチ、シルク `PICO`）

| pin | ネット | 向き | 電気的性質 | 推奨 GPIO (C-MAIN) |
|---|---|---|---|---|
| 1 | `V3A` | 電源入 | 3.3V アナログ、約 3〜4.5mA | **C-PWR `J_RXA` から供給**（Pico の 3V3 は不可） |
| 2 | `GND` | — | アナログ GND | GND |
| 3 | `TH_PWM` | MCU → RX | PWM を R15/C8 (τ=1ms) で平滑 → VTH | PWM 出力（GP6 を転用推奨） |
| 4 | `ENV_ADC` | RX → MCU | DC 0〜約0.43V、出力インピーダンス 5kΩ | **GP26 / ADC0** |
| 5 | `NC` | — | 旧 SHDN。v1.1 で廃止・未接続 | 未接続 |
| 6 | `CMP_OUT` | RX → MCU | OC + 10k プルアップ済み、0/3.3V | **GP2**（PIO 入力） |

配置 (65.1, 20) rot270 → pin1 が y = 20、pin6 が y = 32.5（**pin 番号は +y 方向**）。

### ファームウェア側の要求

- **TH_PWM**: RC が τ = 1ms なので PWM は **100kHz 以上**にする。125kHz なら残留リップル約 6.6mVp-p（duty 50% 最悪値）。
  10kHz だと 82mVp-p でヒステリシス 22mV を超えるので不可。
  実用 duty は 0〜26% なので、**wrap ≥ 1000**（125MHz / 1000 = 125kHz、3.3mV/step）にして分解能を確保する。
- **ENV_ADC**: フルスケールの 1〜2 割しか使わない。ゲインを上げても改善しないので、
  ソフト側で平均化するか §4 の改善提案を適用する。
- **CMP_OUT**: 10k プルアップのためケーブル容量で立ち上がりが鈍る（XH ケーブル 1m ≈ 50pF/m → 約 0.5µs）。
  飛行時間の分解能が要るならケーブルを短くする。Pico 側の内部プルアップは**不要**。
- バースト中は §3.4 の通り 200kHz で断続する。**先頭エッジのみを飛行時間に使う**こと。

### C-MAIN 側との整合（2026-07-28 解決済み）

**本基板は製造済み（基板到着済み）で変更不可のため、C-MAIN 側を本基板の `J2` に合わせた。**
`pcb/build_child_main.py` **v3.1** で対応済み（ERC 0 / ネットリスト一致 / DRC exit=0）。

結線は **C-PWR → C-MAIN → 本基板** の直列で、ケーブルは 2 本ともストレート（ピン入替え無し）:

```
C-PWR J_RXA(XH3)  --XH3 ストレート-->  C-MAIN J_RXA1(XH3)
   1 V3A / 2 GND / 3 GND                    |  V3A/GND を基板上で中継(負荷なし・C_V3A 100n のみ)
                                            v
                                     C-MAIN J_RX1(XH6)
                                            |
                                   --XH6 ストレート 6芯-->
                                            v
                                       本基板 J2(XH6)
```

| J2 pin | ネット | C-MAIN `J_RX1` 同pin | C-MAIN 側の接続先 |
|---|---|---|---|
| 1 | `V3A` | `V3A` | `J_RXA1` pin1 からのパススルー（源は C-PWR `REG3A`） |
| 2 | `GND` | `GND` | GND ベタ |
| 3 | `TH_PWM` | `TH_PWM` | **Pico GP6**（物理9番。PWM3A） |
| 4 | `ENV_ADC` | `ENV_ADC` | Pico GP26 / ADC0（物理31番） |
| 5 | `NC` | `NC` | 未接続（両基板とも no-connect） |
| 6 | `CMP_OUT` | `CMP_OUT` | Pico GP2（物理4番、PIO 入力） |

変更の要点:

- C-MAIN `J_RX1` を **XH4 → XH6**、ピン順を本基板 `J2` と完全一致させた。
- C-MAIN の `RX_EN`（GP6）は**削除**した。本基板は v1.1 で SHDN を廃止しており受け口が無いため。
  同じ GP6 を `TH_PWM`（PWM3A 出力）に転用している。
- 「3V3_ANALOG は C-PWR 直供給」という決定書の原則は、本基板に電源専用コネクタが無い以上
  Y字ケーブルを自作しない限り成立しない。**C-MAIN 上を純パススルー**（負荷を一切繋がない）
  として通す方式に変更した。V3A を消費するのは本基板だけなので、デジタル系のリップルが
  V3A に乗ることはない（レール自体が C-PWR の専用 LDO `REG3A` で分離されている）。

| | B.Cu 回廊: VMID x = 14.9 / BPF_OUT x = 33.6 / V3A x = 4.2, 39.8, 61.9 / CMP_OUT y = 27.2 / TH_PWM x = 63.3 |

### 半固定抵抗の回し方（組立時の注意）

RV1 / RV2 はどちらも**レオスタット接続**（ワイパと片端を短絡）だが、短絡している端子が逆:

- **RV1** (シルク `G1`, 初段): pin2(ワイパ) + pin3 を `ST1_OUT` に接続 → 使う抵抗は pin1–ワイパ間
- **RV2** (シルク `G2`, 後段): pin1 + pin2(ワイパ) を `ST3_OUT` に接続 → 使う抵抗は ワイパ–pin3 間

→ **同じ向きに回すと G1 と G2 は逆方向に変化する**。初回調整時に実測で向きを確認すること。
