# CHILD_PWR (C-PWR) 部品一覧

子機電源・ライト基板で**実際に使う部品**と、その仕様(データシート・CAD図・寸法図・ピン配置)への
リンク集。回路設計・部品配置・定数決めの前に、必ずここのリンク先で
**ピン配置 / 外形寸法 / 電気特性**を確認すること。

- 対応生成スクリプト: `pcb/build_child_pwr.py`
- 基板バージョン: **C-PWR v2.1**(2026-08-02 / **62×70mm** / min_clearance=0.13mm)
  - **外形 100.35×70 → 62×70**(7,025 → 4,340mm² = **38%減**)。根拠は
    `mechanical/docs/子機内装_収まり検討.md` §4。WTE4(ID101.6)200mmチューブの幅広部は
    軸方向160mmしかなく、**v1.0 はそもそもチューブに入らなかった**。
  - **C-MAIN との接続を `J_MAIN`(XH9) 1本に統合**: 旧 `J_MAIN`(XH6)+`J_I2C`(XH5)+`J_CTL`(XH2)
    +`J_RXA`(XH3) = 4コネクタ16ピン → 1コネクタ9ピン。
  - **`J_RXP`(XT30) 削除**: 旧 RX_improved 用の VBAT_M 出力。現行の**製造済み** `RX_improved_mini`
    は `J1`(TD04A) と `J2`(XH6, V3A給電) しか持たず、**完全に未接続の死にコネクタ**だった。
  - ネット名 `LED_PWM` → **`LIGHT_PWM`**（C-MAIN / GPIO表と統一）。
  - 5V/3.3V レール側の受動部品を SMD 化（0603/0805）。**VBAT系(F1/D1/Q1/SW_PWR/R_SH/C_BLK/C_BK1)は
    LTspice 検証済み経路なので不変**。
  - 取付穴ピッチ **54×62mm**（四隅 inset 4.0）。M3穴縁から基板端まで2.4mm確保。
    機体側 `child_vtray_deck.scad` のボス位置も v2.1へ追従済み。
  - 検証: ERC pass / ネットリスト意図照合 pass(17ネット) / **DRC exit=0** / 充填率 37%
- 旧: **C-PWR v1.0**(2026-07-24 / 100×70mm)
- ネット定義の正: `pcb/SPEC_MAIN_PWR_2026-07-19.md`(J_MAIN統合・J_RXP削除は理由付き逸脱)
- 検証記録: `sim/notes.md`(2026-07-23 LTspice 全PASS: 突入31A/逆接遮断/F1速断必須/C_BLK100µ)
- **実装区分**: **基板上のSMD部品は全て JLCPCB の SMT 実装に出す**(2026-08-03 方針変更)。
  対象16点 = `U_INA`(INA226 MSOP-10) / `R_SH`(20mΩ 2512) / `C_VS`(100n 0603) /
  `D1`,`D_LED`(SMBJ15A SMB) / `R_G`,`R_PDL`(100k 0603) / `R_LED`(1k 0603) / `R_GL`(100Ω 0805) /
  `C_BK2`,`C_3D1`,`C_3A1`(10µ 0805) / `C_D5`,`C_3D2`,`C_3A2`(100n 0603) / `LED1`(緑 0805)。
  正は `pcb/jlc_export.py` の `JLC_PARTS['CHILD_PWR']`、出力は `CHILD_PWR_bom_jlc.csv`(9行) /
  `CHILD_PWR_cpl_jlc.csv`(16点)。
  **手はんだで残るのは全てTHT/モジュール**: XT30PW(`J_BAT`,`J_LED`) / ヒューズクリップ`F1` /
  TO-220(`Q1`,`Q2`,`REG3D`,`REG3A`) / トグルSW`SW_PWR` / 電解`C_BLK` / ディスク`C_BK1` /
  ピンソケット`PS1` / JST XH`J_MAIN` / M3穴。
  ※ `D1`/`D_LED` は **C19077569 = Preferred(装着費無料)** を採用。DigiKey購入済の SMBJ15A×10 は予備に回る。
  **単方向TVSなので向きあり** — JLCのプレビューでカソード帯の向きを必ず確認すること。
  他は購入済部品の手はんだ(SMB TVS含む)。

> **記入ルール**: 1部品につき**リンクを最低1つ**(できれば ①データシート/寸法図 ②CAD/3Dモデル

## 3. 電源変換

### 降圧DCDC AE-LXDC55-5V(`PS1`)
- **役割**: VBAT_M(9〜12.6V)→V5D 5V/最大1.5A。**Vin窓 6.0〜14V**(12.6Vは窓内、LTspice検証済)
- SIP3: **1=VIN / 2=GND / 3=VOUT**(7805ライク)。FP: PinSocket 1×03
- 🔴 **2026-08-01 発見（機構に影響）: モジュール基板は 11×25mm で、これを SIP3 で「縦挿し」する。**
  したがって実高さは **ソケット8.5 + モジュール25 = 基板上面から 33.5mm**（下面から 35.09mm）。
  **それまで KiCad の 3D 出力にはピンソケット(8.5mm)しか出ておらず**、`_mech.stl` の最大高さ
  23.52mm は**実物より約10mm 低かった**（`pcb/models3d.py` に `PinSocket_1x03_P2.54mm_Vertical`
  の割当が無く、CLAUDE.md の「モデルが無い部品は無言で消える」に該当）。
  → `pcb/mkmodel3d.py` に `LXDC55_AE_body`(11×25、高さ25) を追加し、`models3d.py` で
  ソケット+モジュールのスタックとして割り当てて解消済み。**P-PWR も同じ部品なので、
  再生成すれば同様に高さが上がる**（未再生成）。
- **配置の要点**: チューブ断面は軸心ほど高さが取れる（軸心で約44mm・幅端で29.3mm）ので、
  **PS1 は基板の幅方向中央 y≈35（＝チューブ軸心）へ寄せてある**。
  幅方向には ±5.5mm しか張り出さないため、アクリル内壁まで約8.7mm の余裕がある。
