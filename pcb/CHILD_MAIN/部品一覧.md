リンク集。回路設計・部品配置・定数決めの前に、必ずここのリンク先で

## 2. センサ

### BNO085 9軸IMU モジュール　Adafruit 4754　（`J_BNO1`）
- **役割**: 姿勢推定（センサフュージョン内蔵の9軸IMU）。専用 SPI0 接続
- ✅ **確定**: **Adafruit 4754**（9軸フュージョン, SPI）。実物FP `AquaBeacon:Adafruit_BNO085_4754`（**25.90×23.36mm**, 1×6が2列/列間17.78mm/2.54ピッチ）。旧「2×5 DIP」は実在せず誤りだった。
- 🔴 **2026-07-31 修正（重大）**: ピン並びは **下列 pad1-6 = `VIN / 3Vo / GND` / SCL / SDA / INT**、上列 pad7-12 = BT / P0 / P1 / RST / DI / CS。旧FPは pad2=GND・pad3=3Vo と**逆**で、そのまま実装すると**モジュール内蔵LDOの出力(3Vo)を基板GNDへ短絡し、本当のGND(pad3)は未接続**になっていた。根拠＝ユーザ提供のベンダ製 KiCad データ `pcb/datasheets/4754.zip`（`MODULE_4754.kicad_mod` のパッド座標＋`4754.kicad_sym` のピン名）。パッド座標も同zipに一致させた（y=±8.89）。
- ✅ **2026-08-01 再検証（Adafruit ブレイクアウトの一次資料で照合。結論＝現状の配線で正しい）**:
  ユーザ指摘「生チップのデータシートではなく Adafruit のモジュール基板を見るべき」を受け、
  **Adafruit Learn ガイド PDF を `pcb/datasheets/Adafruit_BNO085_4754_learn_guide.pdf` に保存**して照合した。
  - 物理並び: ベンダ KiCad の `4754.kicad_sym`（JP1_1-6 = VIN/3VO/GND/SCL/SDA/INT、
    JP2_1-6 = BT/P0/P1/RST/DI/CS）と `MODULE_4754.kicad_mod`（y=±8.89 / 2.54ピッチ）が
    自作FP `AquaBeacon:Adafruit_BNO085_4754` と**完全一致**。
  - SPI 配線（ガイド p.13 の原文）: `SCL→SCK` / **`SDA→MISO`** / **`DI→MOSI`** / `CS` / `INT` / `RST`、
    そして **「P0 と P1 は共に 3V」**。build スクリプトの割当と一致 → **変更不要**。
  - 🆕 **ガイドから新たに判明した注意点（生チップDSには無い情報）**:
    1. **`SCL`/`SDA` はレベルシフタ経由で 10kΩ プルアップ付き**（3–5V ロジック対応のため）。
       SPI モードではここを **SCK と MISO** が通るので、**SPI クロックは 1MHz 程度に抑えること**
       （`Adafruit_BNO08x` ライブラリの既定と同じ）。`DI/CS/INT/RST/P0/P1` は直結で影響なし。
    2. `P0`/`P1` は基板上で**プルダウン**されており既定は I2C。SPI には High 固定が必須＝
       現状の V3D 直結が正しい（ここを開放にすると I2C モードで起動して一切応答しない）。
    3. ガイドは **「INT と RST の省略は不可」**と明記（"do not!"）。現状どちらも接続済み。
- SPI: SCK=SCL(pad4) / MISO=SDA(pad5) / MOSI=DI(pad11) / CS=CS(pad12) ＋ INT(pad6) / RST(pad10)。**SPIモード選択は P0(pad8)/P1(pad9) を共に V3D**。3Vo(pad2)・BT(pad7) は NC。
- ⚠ **未対応**: CEVA データシートは「Pin 6 (PS0/WAKE) は GPIO へ接続すること」と明記。現状は空きGPIOが無く V3D 固定。（Adafruit 公式配線・Adafruit_BNO08x ライブラリはこの状態を前提にしている）

### Celsius Fast-Response 水温センサ（`J_TEMP1` = **JST-GH 4極**で外部接続）★v4.0 新規
- **役割**: 水温計測（I2C）。Blue Robotics Celsius Fast-Response Temperature Sensor (R1)
- **中身**: TE **TSYS01** / **I2C アドレス 0x77** / 電源 3.3–5.5V / ピーク 1.4mA /
  精度 ±0.1°C(−5〜50°C) / 応答 1秒(流速0.5m/s)・2秒(静水) / 使用深度 0〜975m
- **アドレス衝突なし**: MS5837=0x76 / DS3231=0x68 / AT24C32=0x57 / INA226(C-PWR)=0x40
- **コネクタ**: **XH4（`B4B-XH-A`）**。**2026-08-03 に JST-GH から変更**。
  v4.0〜v4.3 は「センサ付属ケーブルが 4極 JST-GH だから基板側も GH（`SM04B-GHS-TB`）にすれば
  変換ケーブル不要」という前提だったが、**実際はユーザが XH コネクタでケーブルを自作している**
  ため、GH（1.25mmピッチ）では**物理的に嵌合しない**という誤りだった。
- **ピン順 `1=V3D 2=GND 3=SDA 4=SCL`**。自作ケーブルなのでピン順は自由 → **`J_PRS1` および
  P-MAIN の `J_PRS1`・`J_MAG1`・`J_TEMP1` と完全に同一**にした。
  これで **I²Cセンサ用ケーブルが親子・センサ間で全て共通**になり、取り違えても致命傷にならない。
- **シルクは線色順に `R B W G`**（赤=Vin / 黒=GND / 白=SDA / 緑=SCL）。
- 配線時は Celsius 側の線色↔XHハウジングの並びを、このシルクに合わせて圧着すること。

- **push-push（押し込みロック／再度押すと自動排出）**。JLCPCB で最も流通している microSD ソケットで、
  **JLCPCB の SMT 実装に出せる**（旧 Molex 104031-0811 は JLC 在庫が無く手はんだ前提だった）。
