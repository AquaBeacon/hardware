# 組立・ブリングアップ手順書 — C-PWR / P-PWR / C-MAIN / P-MAIN

対象: `CHILD_PWR` `PARENT_PWR` `CHILD_MAIN` `PARENT_MAIN` の4基板。
TX/RX 系は別ファイル `pcb/BRINGUP.md`。

期待値の根拠は `sim/notes.md`(LTspice 検証値)と各基板の `部品一覧.md`。
**期待値から外れたら次の段へ進まないこと。** 水中機は密閉後にアクセスできないため、
蓋を閉める前にここを全部通す。

---

## 0. 全体の順序(これを守る)

```
C-PWR 単体  →  C-MAIN 単体(外部電源)  →  C-PWR + C-MAIN 接続  →  周辺(RX/センサ/ライト)
P-PWR 単体  →  P-MAIN 単体(外部電源)  →  P-PWR + P-MAIN 接続  →  周辺(TX/GNSS/カメラ)
```

**電源基板を先に完成させる。** メイン基板を未検証の電源につなぐと、
LDO の実装ミス1つで Pico・センサ・microSD を一度に失う(全部が同じ V3D レール上にある)。

### 共通: 実装順序

1. SMD(0603 → 0805 → SOT-23 → MSOP-10 → コネクタ類)
2. THT の背の低いもの(抵抗・ダイオード・セラコン)
3. TO-220 / 電解コンデンサ / ピンソケット
4. 背の高いもの(トグルSW・XT30・タクトSW・縦挿しモジュール)
5. **モジュール類(Pico / DS3231 / BNO085 / LXDC55 / MYMGK)は最後**。
   ソケット実装にしてあるので、基板側の電源チェックが通るまで挿さない。

### 共通: 通電前チェック(テスタ、電源を繋がない状態)

| 測る場所 | 期待値 | 外れたら |
|---|---|---|
| GND ↔ 各電源レール(V5x / V3x / VBAT_M) | **数十kΩ以上**(電解が充電されるので値は動く) | **数Ω台なら半田ブリッジ**。必ず原因を取り除く |
| 各レール同士(V5D↔V3D 等) | 開放〜高抵抗 | 低ければブリッジ |
| コネクタのピン間 | 開放 | ブリッジ |
| **XT30 の極性**(FP刻印 pad1=「−」pad2=「+」) | 目視 | 逆に配線したら Q1 が遮断して何も動かない(壊れはしない) |

## 1. CHILD_PWR (C-PWR v2.3)

### 1-1. 準備

- **PS1(AE-LXDC55)・REG3D・REG3A を実装しない状態で始める。**
  まず VBAT 系(ヒューズ→逆接保護→スイッチ→シャント)だけを確認する。
- SW_PWR は **OFF**。

### 1-2. 初回通電(電流制限つき)

安定化電源を **12.0V / 電流制限 100mA** に設定して J_BAT へ(XT30の極性に注意)。

| # | 測定点 | 条件 | 期待値 | 判定 |
|---|---|---|---|---|
| 1 | F1 西クリップ(VBAT) | SW_PWR OFF | 12.0 V | |
| 2 | F1 東クリップ(VBAT_F) | SW_PWR OFF | 12.0 V(降下 <0.1V) | ヒューズ導通 |
| 3 | `R_G` の GND 側でない端(QG) | SW_PWR OFF | **≈0 V** | Q1 ゲートが 100k で引き下げられている |
| 4 | SW_PWR pad1(VBAT_P) | SW_PWR OFF | 12.0 V | Q1 が導通(Pchハイサイドは常時ON側) |
| 5 | **C_BLK pin1(VBAT_M)** シルク `VBAT_M` | SW_PWR **ON** | 12.0 V | シャント込みで降下は数mV |
| 6 | 電源の表示電流 | SW_PWR ON, 安定後 | **< 5 mA** | 大きければどこかで負荷/短絡 |

> **突入について**: 実電池では投入時に **31.4 A(12.6V)/ 21.8 A(9.0V)** が
> F1・SW_PWR・Q1 を通る(I²t = 0.029 A²s ≪ 速断3Aの 5 A²s なので**ヒューズは飛ばない**)。
> 電流制限つきのベンチ電源では起きないので、この段階では観測されないのが正常。

### 1-3. 逆接続の確認(やっておく価値がある)

電源の極性を**わざと逆**にして 12.0V / 100mA で加える。

| 測定点 | 期待値 |
|---|---|
| VBAT_M | **≈0 V**(実測 0.021V) — Q1 が遮断している |
| 電源の表示電流 | 制限値に張り付く(TVS D1 が導通) |

**5秒以上続けないこと。** 実電池だと TVS に 82.8A が流れ、ヒューズが溶断するまで持ちこたえる設計。

### 1-4. 電源レール(PS1 / REG3D / REG3A を実装してから)

電流制限を **300mA** に上げる。SW_PWR ON。

| 測定点 | 期待値 | 許容 | 根拠 |
|---|---|---|---|
| **PS1 pin3 (V5D)** シルク `V5D` | **4.98 V** | 4.75〜5.25 V | LTspice 4.984V |
| **REG3D pin1 (V3D)** | **3.29 V** | 3.20〜3.40 V | LTspice 3.285V |
| **REG3A pin1 (V3A)** | **3.30 V** | 3.20〜3.40 V | LTspice 3.298V |
| LED1 | 緑点灯 | | V5D/1k ≈ 2.3mA |
| REG3D / REG3A の表面温度 | 室温+数℃(無負荷) | | 満負荷でも Tj上昇 27.7K 想定 |

> **NJU7223F33 は 1=VOUT / 2=VIN / 3=GND で 78xx 系と逆順**
> (一次資料 `pcb/datasheets/NJU7223_NJR_akizuki.pdf` p.1 で照合済み)。
> **V3D が 5V になっていたら向きが逆**。即座に切って再確認する。

### 1-5. J_MAIN(C-MAIN へ出す9ピン)の確認

ケーブルを挿す前に、コネクタのピンで直接測る。

| pin | ネット | 期待値 |
|---|---|---|
| 1 | V5D | 4.98 V |
| 2 | V3D | 3.29 V |
| 3 | V3A | 3.30 V |
| 4, 7 | GND | 0 V |
| 5 | I2C_SCL | 開放(プルアップは C-MAIN 側・既定DNP) |
| 6 | I2C_SDA | 同上 |
| 8 | INA_AL | 開放(C-MAIN 側 R_AL でプルアップ) |
| 9 | LIGHT_PWM | **0 V**(R_PDL 100k で引き下げ) |

### 1-6. ライト駆動段(ライトを繋がずに)

`J_MAIN` pin9 (LIGHT_PWM) に 3.3V を加える。

| 測定点 | LIGHT_PWM=0V | LIGHT_PWM=3.3V |
|---|---|---|
| Q2 ゲート(R_PDL の非GND側) | 0 V | 3.3 V |
| J_LED pin1 (LED_N) | VBAT_M | **要実測**(下記) |

> ⚠ **要実測(未確定)**: Q2(TK7R4A10PL)は **Vth 最悪 2.5V** の品を Pico の 3.3V で直接駆動している。
> 想定負荷 1A なら飽和領域に十分入るはずだが**保証はない**。
> **ライトを繋いだ状態で Vgs=3.3V 時の Vds を必ず実測すること**(数十mV 以内なら OK)。
> ここが数百mV あるとリニア領域で発熱する。**ライトを大型化する場合は必ず再検証**。

> ⚠ **要確認**: ライトの実定格が未確定。LTspice は **Vf≈9V + Rs=3.6Ω(12.6Vで 1.0A)** の
> 仮定でしか検証していない。定電流ドライバ内蔵品だと挙動が全く違う。
> **F1(3A) / SW_PWR(3A) / R_SH(FS 4.1A) の余裕は全部この 1A 前提**なので、
> 実ライトの定格が分かったら `LTspice/CHILD_PWR.cir` を更新して再検証すること。

## 2. PARENT_PWR (P-PWR v1.4)

C-PWR とほぼ同じ手順。差分だけ書く。

### 2-1. スイッチの操作順序(**重要**)

> **`SW_TX` は必ず `SW_PWR` より先に(= 主電源を入れる前に)入れておく。**
>
> 通電中に SW_TX を入れると、放電しきった TX 基板の `C1`(470µF)へ突入が流れる:
> - 突入ピーク **36.1 A(12.6V)/ 25.4 A(9.0V)** が定格 3A のトグル接点を通る
> - **電池終止(9.0V)では VBAT_M が 5.13V まで落ち、LXDC55 の Vin 下限 6.0V を 74µs 割る**
>
> 先に入れておけば検証済みの冷間投入に収まる(`sim/notes.md` 2026-08-03節)。
> **運用中に送信を止めたいときは `TX_PWM` を Low 固定にする**(TC4427 出力Lo → 2SK4017 OFF)。
> SW_TX を通電中に操作する必要はない。
>
> なお I²t は最大 0.107 A²s で速断3Aの 5 A²s を大きく下回るので、**ヒューズは飛ばない**。

### 2-2. 電源レール

電流制限 **300mA**、SW_PWR ON / SW_TX ON。

| 測定点 | 期待値 | 許容 |
|---|---|---|
| **C_BLK pin1 (VBAT_M)** シルク `VBAT_M` | 入力電圧 −数mV | |
| J_TX pin2 (VBAT_TX) | VBAT_M と同じ | SW_TX ON のとき |
| **PS_A pin3 / C_5L1 pin1 (V5L)** | **4.98 V** | 4.75〜5.25 V |
| **REG3S pin1 (V3S)** | **3.29 V** | 3.20〜3.40 V |
| **C_5C1 pin1 (V5C)** カメラ系 | **4.96 V** | 4.75〜5.25 V |

> **PS_B(AE-MYMGK00506ERSR)は Vin 窓 8〜15V**。3S LiPo の終止 9.0V が下端に近いので、
> ベンチでは **9.0V でも V5C が 4.75V 以上を保つ**ことを確認しておく。
> PG(1)=開放 / CTRL(2)=開放 で出力 ON。**実物シルクで挿し向きを確認してから通電すること。**

### 2-3. 出力コネクタ

| コネクタ | pin → ネット |
|---|---|
| `J_MAIN`(XH6) | 1,2=V5L / 3,4=GND / 5,6=V3S |
| `J_I2C`(XH5) | 1=V3S / 2=GND / 3=SDA / 4=SCL / 5=INA_AL |
| `J_POD`(XH2) | 1=V5C / 2=GND |
| `J_TX`(XT30) | pad1(−)=GND / pad2(+)=VBAT_TX |

## 3. CHILD_MAIN (C-MAIN v4.5) / PARENT_MAIN (P-MAIN v5.8)

### 3-1. 単体確認(電源基板を繋がず、外部電源で)

**Pico・DS3231・BNO085・microSD カードは挿さない。**

`J_PWR1` に外部電源を入れる(C-MAIN: pin1=V5D 5.0V / pin4=GND。P-MAIN: pin1,2=V5D / pin3,4=GND)。
電流制限 **100mA**。

| 測定点 | 期待値 |
|---|---|
| 電源の表示電流 | **< 10 mA**(LED_PWR 分のみ) |
| LED_PWR(緑) | 点灯 |
| GND ↔ V3D | 3.3V を別途 `J_PWR1` pin2(C-MAIN)/ pin5(P-MAIN)から与えて確認 |
| `TP_GND1`(シルク `GND TP`) | 0 V。**以降スコープのグランドはここに咬ませる** |

### 3-2. 接続確認(電源基板と繋ぐ前に)

**基板間ケーブルはストレート**。作った後、必ず導通で1:1を確認する。

| 区間 | コネクタ | 本数 |
|---|---|---|
| C-PWR `J_MAIN` ↔ C-MAIN `J_PWR1` | XH9 | ストレート9芯 **1本** |
| P-PWR `J_MAIN` ↔ P-MAIN `J_PWR1` | XH6 | ストレート6芯 |
| P-PWR `J_I2C` ↔ P-MAIN `J_I2CP` | XH5 | ストレート5芯 |
| C-MAIN `J_RX1` ↔ RX基板 `J2` | XH6 | ストレート6芯(RX基板は製造済み=変更不可) |
| P-MAIN `J_TX1` ↔ TX基板 `J2` / `J_TXT1` ↔ `J5` | XH2 / XH3 | ストレート |

**I²C センサ用ケーブルは全部同じピン順**(`1=V3D 2=GND 3=SDA 4=SCL`)。
C-MAIN `J_PRS1`・`J_TEMP1`、P-MAIN `J_PRS1`・`J_MAG1`・`J_TEMP1` で共通。
Celsius は XH で自作するので、**シルクの `R B W G`(赤=Vin/黒=GND/白=SDA/緑=SCL)に合わせて圧着**する。

### 3-3. Pico を挿す前に

| 確認 | 理由 |
|---|---|
| `J_PWR1` pin1 の V5D = 4.98V | Pico は VSYS(物理39)給電。1.8〜5.5V の範囲内 |
| Pico の 3V3(物理36)が **NC** であること | 基板の V3D は電源基板の LDO 製。ここを繋ぐと出力同士がぶつかる |
| V3D = 3.29V | 全センサ・microSD・LCD・RS485 がこのレール |

### 3-4. Pico を挿してから

| 項目 | 期待値 | 外れたら |
|---|---|---|
| 消費電流(V5D) | 50〜120 mA(WiFi 動作で変動) | 過大なら短絡 |
| I²C スキャン | **C-MAIN**: 0x3E(LCD) 0x40(INA226) 0x57(EEPROM) 0x68(DS3231) 0x76(MS5837) 0x77(TSYS01)<br>**P-MAIN**: 上記 + 0x1C or 0x1E(LIS3MDL) | 下記 I²C の項へ |
| `LED_STATUS`(赤)を GP14(C)/GP2(P) で点滅 | 点滅する | |
| microSD | マウントできる | 下記 SD の項へ |

#### I²C が不安定なとき

- **プルアップ `R_SDA` / `R_SCL`(4.7k)は既定 DNP**(未実装)。
  まず **無通電で SDA-V3D / SCL-V3D 間の抵抗を実測**する。
  - 4.7kΩ 前後 → DS3231(ZS-042)のオンボードプルアップが効いている。追加不要。
  - 4.7kΩ を大きく超える / 開放 → `R_SDA` `R_SCL` を実装する。
- **それでも波形の立ち上がりが鈍い場合は 2.2k を検討**する。
  このバスは **2基板 + 4本のケーブル**に跨がり(C-MAIN 内 + C-PWR への9芯 + MS5837 + Celsius + LCD)、
  総容量が 400pF を超えると 4.7k では tr > 1µs で 100kHz 規格を外れる。
  **`TP_GND1` を基準に SCL の立ち上がりを実測して決めること。**

#### microSD が不安定なとき

- `R_SDCS`(10k, V3D→SD_CS)が実装されているか。これが無いと Pico 起動前に CS がフロートする。
- `R_CD`(47k)と `SD_CD` の論理を実測で確認する(カード有り/無しでどちらが Low か)。
  一次資料は `pcb/datasheets/microSD_TF-01A_KoreanHroparts_C91145.pdf`。
- SPI 配線長は約35mm。まず低速(1MHz)で動かしてから上げる。

### 3-5. C-MAIN 固有

| 項目 | 期待値 |
|---|---|
| `BTN_ADC`(GP27) | 無押下 3.3V / UP 0V / ENTER 0.82V / DOWN 1.65V |
| バックライト | `BL_PWM`(GP28) Hi で点灯。LED 電流 ≈19mA(V5D→R_BL 100Ω) |
| `LCD_RST` | 電源投入から約1ms(10k×100n)で 3.3V へ立ち上がる |
| `LEAK`(GP22) | 電極開放で **3.3V に近い High**。電極を水に浸すと Low |
| `TH_PWM`(GP6) | **125kHz 以上・wrap≥1000** で出力すること。`R_THP`+`C_THP` で鈍らせてから J_RX1 へ出る。**duty↔VTH の関係は変わらない** |
| `ENV_ADC`(GP26) | RX の包絡線。0.17〜0.43V(RX側で1/2分圧済み)。**フルスケールの13%しか使わないので、ファーム側でオーバーサンプリング/平均化して実効分解能を稼ぐこと** |

> `LEAK` は `R_LEAK` を **100k** に変更済み(v4.5)。1M だと RP2350 の入力リーク(最悪±1µA)
> だけで最大1.0V 落ち、乾燥時の High が VIH ぎりぎりになるため。`C_LEAK` 10n で τ=1ms。

### 3-6. P-MAIN 固有

| 項目 | 期待値 |
|---|---|
| `BTN_ADC`(GP26) | C-MAIN と同じ |
| `TX_PWM`(GP16) | 200kHz。`R_TXP` 100Ω 経由で `J_TX1` へ |
| `TX_TEMP_ADC`(GP27) | 25℃で ≈1.65V / 85℃で ≈0.32V。**R_TTD 100k の分だけ読み値が約 −5.7% ずれるのでファームで補正する**(未補正だと25℃付近で約 +2.9℃ の誤差) |
| TX 温度の故障判別 | NTC断線 → ≈3.3V / `J_TXT1` ケーブル断線 → ≈0V / NTC短絡 → ≈0V。**いずれでも送信停止すること** |
| `SPR_PPS` / `SPR_EVENT` | 各 100Ω 直列。**SPRESENSE 拡張ボードの JP1 は必ず 3.3V 側**(シルク `JP1=3V3!`) |
| GNSS | UART1(GP8/GP9) 9600 or 38400bps、PPS が GP6 に 1Hz |

## 5. 単体試験時の仮結線

| 基板 | ピン | 処置 |
|---|---|---|
| C-PWR / P-PWR | `J_MAIN` の I2C | 単体試験では開放でよい(プルアップはメイン基板側) |
| C-MAIN | `J_RX1` pin5 | RX 側 NC。**開放のままにする**(GND に落とさない) |
| C-MAIN / P-MAIN | Pico 3V3(物理36) | **NC のまま**。絶対に V3D へ繋がない |
| P-MAIN | `J_SPR1` | SPRESENSE 拡張ボードは自前の電源から給電。この基板からは供給しない |
| C-MAIN | BNO085 P0/P1 | 両方 V3D 固定(SPIモード選択)。**ファームから叩けないので、WAKE を使う設計にはしない** |

## 6. 蓋を閉める前の最終確認

```
[ ] 全レールの電圧を TP_GND1 基準で再測(冷間・30分連続動作後の2回)
[ ] I2C スキャンで全デバイスが見える
[ ] microSD に書いて読める
[ ] 漏水電極を短絡させて LEAK が Low になる(子機)
[ ] SW_TX を SW_PWR より先に入れる運用になっている(親機)
[ ] LCD が表示され、3ボタンが判別できる
[ ] テザー(RS485)でもう一方の基板と通信できる
[ ] 3D干渉: pcb/3d/<board>_mech.stl と筐体で確認済み
[ ] コネクタが全部挿さっていて、ケーブルの曲げ半径がペネトレーターに対して無理をしていない
```
