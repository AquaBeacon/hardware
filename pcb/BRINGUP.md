# 組立・ブリングアップ手順書 — AquaBeacon TX/RX (2026-07-11)

本書は基板単体の火入れ手順。正式なベンチ試験の合否基準は
`../docs/AquaBeacon_実験検証仕様書.md` の **E0a(TX: ΔT<20K/平均電流<100mA/振幅±10%)・
E0b(RX: 利得60±3dB/f0=200±20kHz/ADC較正表)** に従うこと。本書合格 → E0a/E0b実施の順。

期待値はすべてLTspice検証(`sim/notes.md`, `sim/runs/*/measure.json`)に基づく。
**測定器**: オシロ(×10プローブ, 帯域≥20MHz)、電流制限付き安定化電源、LCRメータ、ファンクションジェネレータ(FG)。

## 共通: 組立順序

1. 背の低い順に実装: SMD(TVS/オペアンプ/コンパレータ) → 抵抗/小信号ダイオード → セラコン → 電解/インダクタ → ピンヘッダ → 端子台 → 大物。
2. 実装後、通電前に **GND-電源間の抵抗値** をテスタで確認(数kΩ以上あること。数Ω台なら半田ブリッジを疑う)。
3. 初回通電は必ず **電流制限を設定**(TX: 12V/0.3A、RX: 3.3V/50mA)して行う。

## TX_improved (1石 + 保護)

前提: J2には**5Vゲートパルス**が必要(3.3V GPIO直結不可 — 簡易モデルでも駆動不足の懸念、`sim/notes.md`注1)。

1. **無負荷通電**: J1に9V(制限0.1A)。静止電流がほぼ0であること(FET off)。
1b. **ダミー負荷推奨**(実験検証仕様書E0a): 整合確認前は実振動子でなく
   **実測C0相当のコンデンサ+直列10Ω** をJ3に付けて波形確認するのが安全。
2. **L1同調確認**: TD04AをJ3に接続し、LCR実測C0が1260pFからずれていた場合は
   `sim/tx_improved_verify.py` の `.param` を書き換えて再シミュ → L1を選び直す(f_res=1/(2π√(L·C0))=200kHz)。
3. **バースト駆動**: J2に 200kHz / 20サイクル / 5Vpp バースト(FG、繰り返し≥10ms)。
   - Q1ドレイン電圧ピーク: **約33V @9V / 約44V @12V**(オシロ×10で確認)
   - XD(J3)振幅: **約34Vpp @9V / 約45Vpp @12V**
   - Vdsが50Vを超える場合は異常(TVS動作=毎サイクル導通は発熱する)→ L1同調ズレを疑う
4. **故障試験(任意)**: TD04Aを外して駆動 → VdsピークがTVSクランプで**60V未満**(シミュ53.4V)に収まること。
5. 12V常用は余裕が小さい(44V/定格60V)ため、12V運用が主なら TX_advanced を使う。

## TX_advanced (MIC4427 + 2SK4017×2 プッシュプル + 1:5トランス)

前提: トランスは手巻き(EEコア、一次100µH×2センタタップ、二次2.5mH)。J2は**3.3V PWM直結可**。

1. **トランス単体検査**: 実装前にLCRで一次半巻線L(目標100µH×2)・二次L(2.5mH)・極性(センタタップ対称)を確認。
2. **無負荷通電**: J1に12V(制限0.1A)。PWM無入力(両Low)で静止電流ほぼ0(両FETオフ=アイドル安全設計)。
3. **PWM入力**: A/B相補(デッドタイム≥100ns、200kHz、20サイクルバースト)をJ2へ。**A/B同時Highは禁止**。
   - Q1/Q2ドレイン: 対称に **2×V12≈24V** 台へスイング。Vdsピーク **約26.5V @9V / 36.3V @12V**
   - XD(J3)振幅: **R_DMP=220Ωで約294Vpp @12V**(221Vpp @9V)
4. **駆動振幅調整**: TD04Aの許容駆動確認後、R9(R_DMP)を交換して調整
   (実測マップ: 47Ω→595Vpp / 100→453 / 150→370 / 220→294 / 330→223 @12V)。
5. **電流確認**: 12V連続バーストでFETピーク電流≈1.7A(定格5A)。FET/トランスの発熱を初回は指で確認。

## RX_improved / RX_advanced (受信チェーン)

前提: 3.3V単電源(Pico等から供給)。J2ピン配置は基板シルク参照(V3A/GND/TH/ADC/SHDN/CMP)。
⚠ SHDNはTLV3501ピン直結でプル抵抗なし: **High(≥2.4V @3.3V)で停止、Low(≤1.6V)で動作**
(TLV3501データシートSBOS321E: (V+)−0.9V以内=停止)。J2のSHDNを未接続のまま試験すると
フロートで動作不定になるため、単体試験時はGNDへ短絡すること。

1. **通電・バイアス確認**: V3A=3.3V(制限50mA)。静止電流〜数mA。
   - **VMID(C9両端)=1.65V ±0.1V** を最初に確認(ここがずれると全段動かない)。
   - 各オペアンプ出力DC≈1.65V。
   - ゲイン設定の対応(デバッグ用): 初段×20 = 1+R4/R3 ≒ 19k/1k+1、後段×25 = 1+R9/R8 ≒ 24k/1k+1
     (BOM値とシミュ定数の一致は机上照合済み。MFB定数も `sim/notes.md` の値とBOMが一致)
2. **AC特性**: FGから J1 に 200kHz 連続正弦波 1mVpp(50Ω出力+分圧で作る)を入力。
   - チェーン利得: **約60dB**(1mVpp→約1Vpp、U2出力またはENVで確認)
   - ピーク周波数: RX_i **197kHz** / RX_a **202kHz**(±5kHz以内でなければBPF定数を疑う)
   - -3dB帯域: **約75kHz**
   - RX_aのみ: 400kHzで**-24dBc**程度の抑圧(単段比+12dB)を確認可能
3. **検波・コンパレータ**: 200kHz/20サイクルバースト 1mVpp入力。
   - ENV(検波出力): バーストに追従する包絡線(τ=15µs)
   - CMP出力: バースト開始から **RX_i 約24µs / RX_a 約31µs** で発火(RX_aは群遅延+7µs — ウォーク補正の較正に組み込む)
   - 誤発火(入力無しでCMP発火)がないこと
4. **入力保護確認(任意)**: 5Vpp入力で入力ノードが**-0.75〜+4.05V**にクランプされること。
5. **ADC出力**: ENV_ADC(10k:10k分圧)がPicoのADC範囲(0-3.3V)に収まること。
6. **-20dB入力減衰ジャンパ(近距離試験用)**: 水槽ショートレンジ(E0c)・E1の1m点では
   過大入力になるため、実験検証仕様書は初段入力への-20dB減衰挿入を要求している。
   **基板上には未実装** → J1(端子台)とTD04Aの間に外付けL型パッドで対応する。
   例: 直列910Ω+シャント110Ω。減衰比=110/(Rsrc+910+110)で、TD04A実効源抵抗
   ≈100Ω(simモデルR_S)なら0.098≈-20.2dB。基板側入力は R1 100Ω→AC結合→100kバイアス
   の高インピーダンス受けなので分圧比への影響は無視できる。挿入有無を必ずログに残す。

## 実機≠シミュの既知ギャップ(`sim/notes.md`「モデル化の注意」)

- 2SK4017は簡易モデル → 実機でRDS(on)・スイッチング損失・ゲート駆動の実力を確認。
- TVSクランプ電圧の電流依存はデータシート値で最終確認。
- トランスK=0.99仮定 → 実巻線ではL1同調が動く。**L1は実測合わせが前提**。
- OPA2607/OPA607の3.3V単電源適合は発注前確認(ORDERING.md)。
