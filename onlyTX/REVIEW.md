# onlyTX 机上レビュー (2026-07-11, 自動レビュー — ファイル本体は無変更)

手作業中の `onlyTX.kicad_sch` を読み取りレビューした結果。作業途中と思われるため
「現時点で直しておくと後で効く点」を優先度順に挙げる。

## 重要度: 高

1. **Q3 (2SK4017) のフットプリントが SOT-523 になっている**
   - シンボルのDatasheetリンクも 2SK3019 (MCC, SOT-523) を指している。
   - 2SK4017(東芝)は **TO-251 (PW-Mold2) のTHT品**(60V/5A)。SOT-523は別物の
     2SK3019 (**30V/0.1A/RDS 2Ω**) 用。
   - もし実体が2SK3019のままだと: TX動作時のドレインピークは **33V@9V / 44V@12V**
     (LTspice実測, `sim/notes.md`) で **Vds 30V定格を即座に超過**、電流も桁違いに不足。
   - 対処: フットプリントを `Package_TO_SOT_THT:TO-251-3_Vertical` に変更し、
     実部品も2SK4017(秋月 I-07597)を使う。ピン配置は 1=G, 2=D(タブ), 3=S
     (`pcb/datasheets/2SK4017_toshiba.pdf` で確認済み)。

2. **電源レール割当の確認推奨**(結線トレースの結果)
   - ~~+24V使用~~ は誤指摘: power:+24V シンボルを値変更して **+5V / +9V** として
     使用している(KiCad 8以降はValueがネット名になるので動作上は正しい。
     紛らわしいので `power:+5V` / `power:+9V` シンボルへの置換を推奨)。
   - ただし割当が **ドレイン側レール(L1経由)=+5V、TC4427のVS=+9V** になっている。
     ドレイン5Vでは駆動振幅が約18Vpp止まり(9V時33Vpp/シミュ実測)。意図的な低電圧
     テストでなければ **ドレイン=+9V、ドライバVS=+5V(または両方9V)が自然**。要確認。

## 重要度: 中

3. **ドレイン過電圧保護(TVS)・電源保護が見当たらない** — ゲート側は
   BZV55C15+10k+22Ωで保護されているが、ドレインTVS(SMBJ48A等)と電源側
   (SMBJ15A+バルク100µF)が無い。振動子外れ時のフライバック(sim実測53V@12V)対策に必須。
   参考実装: `pcb/TX_improved/`(同構成・DRC 0で発注可能状態)。

4. **フットプリント未割当の部品が多数**(L, R, C, Crystal) — PCB化前に要割当。
   TD04AをCrystalシンボルで代用している場合、実基板側は端子台(参考: TX_improvedのJ3)。

## 良い点(結線トレースで確認済み)

- ゲート駆動トポロジは健全: GPIO11 → TC4427(INA) → 直列R → ゲート、
  G-S間に BZV55C15 ツェナークランプ + 10kプルダウン、**未使用INBはGNDに固定**(定石どおり)。
- ドレイン → L1 → 電源、ドレインから直列R+振動子(Crystalシンボルで代用)→GND —
  `pcb/TX_improved` と同じ直列同調構成。
- 残る電気的な不足はドレインTVSとドレイン側レールのバルクコンデンサのみ
  (C1はドライバ側+9Vレールに接続済み)。
